# 视觉时变语义条件：路线修正

2026-09-18。本文保留路线决定时的设计；当晚已完成256片视觉语义提取和六臂30轮训练，见[实测](VISUAL_SEMANTIC_PILOT_RESULTS_20260918.md)。30轮高频运动仍过强，不能宣布自然动态成功。参考形状干预仍为未执行proposal。

## 监督各自的用途

保留原生完整动作轨迹作为生成目标。r3阶段标签和像素运动只用于诊断，不要求每段动作具有完整起势/保持/回落。阶段覆盖低否决的是当前完整事件与等待分布拟合，不能据此禁止全部连续运动学习。像素残差不是新的眉动作真值。

旧run27/29用动作残差投影构造强度并乘固定情感方向；activity30用系数速度阈值，均非独立视觉情感监督。目前未找到经过核验的视觉VA与替代语义条件的匹配实验，不能说VA已被证明无效，也不能说换视觉监督必然成功。

## 主比较

优先核验冻结外部视觉情感教师，以直接视觉VA作为明确定义的基线；替代臂为窗口表情类别软分布。实际教师支持的输出、权重来源与时间稳定性待检查，不能预先假定已有合格标签。

类别分布描述表达类别的证据组合，不是强度。最大概率、熵、1-p(neutral)都不得换名为物理强度；类别映射到预设二维坐标也不能冒充独立VA标签。若类别概率片内饱和或主要随口型抖动，就不适合作动态替代。VA本身同样不唯一指定眉方向和持续时间。

首轮只比较两种语义表示，不同时增加AU、文本、大维embedding与新活动头。窗口时钟在实验前固定，平滑不能制造教师原本没有的时间信息。外部视觉教师减少与当前BS提取器的同源循环，但仍是伪标签。

## 接入方式

保留B0/口部输出、独立身份参考和全局audio emotion入口。保留已有motion-global到audio-global教师关系；全局模块冻结时不称其仍接受在线蒸馏。

训练端视频产生低率语义标签，音频学生预测相同坐标。语义通过可学习投影/调制进入现有上脸随机轨迹生成器，不能直接加到BS，也不能替换旧4组几何状态后仍沿用固定lift/P-Q规则。完整motion轨迹教方向、形状与协调；随机状态表示一对多变化，历史按部署使用已生成动作。

初期仅更新上脸，其他43通道复制共同基座。该数值保护不等于新的身份、情感或唇音同步认证。查询视觉条件只用于训练和明确的oracle诊断；部署使用音频、独立身份参考、随机状态，额外用户情感控制单列。

## 有界验证

1. 固定fit小样本验证教师片内变化、轻微图像扰动稳定性、与嘴部/头姿/眨眼的共现。不按r3或像素相关筛选好片证明成功。
2. 接收端和音频学生并行小试。接收端同预算比较静态、正确视觉语义、打乱语义；学生比较静态与时变预测，单列片内变化和同类别错配。不能等学生完美后才验证生成。
3. 接收训练纳入严格句级交叉拟合的学生条件，避免仅用准确视觉标签训练、推理突然改用预测。视觉oracle成功仅证明条件有控制价值，预测分数好不能替代最终生成。
4. 固定样片、多seed、动态分布及连续视频，同时检查口部保护。自然多样性与音频时机分别结论；抖动、增大方差、全局分类改善均不足。

若视觉条件也不能形成合理控制，定位语义信息或接收通路；若只有视觉条件有效，定位学生；若时变不优于静态，不把全局语义收益称动态增益。不得无依据追加同类轮次。

原设计之后已完成教师选择、提取和首轮训练，实际终点以[视觉语义实测](VISUAL_SEMANTIC_PILOT_RESULTS_20260918.md)为准。前序状态监督实测见[BROW_PHASE_STATE_V3_RESULTS_20260918.md](BROW_PHASE_STATE_V3_RESULTS_20260918.md)。
