# 四组眉眼活动可预测性：固定时钟分离验证

本协议在新实验训练/评分之前固定。先验证活动条件是否可学，不修改生成器，不以GT条件驱动成功代替音频成功。前序高维/韵律轨迹分类未过时序对照，继续要求音频选唯一完整几何轨迹缺少依据。

旧run22 events使用19个upper-face通道（含blink/gaze）的单个L1强度field的相邻bin差分，固定三类logits；真实输出未胜过reverse。motion_process30已使用四组时长与有方向Gaussian位移，其主要泛化损失来自位移项。因此本次实质变化是**移除方向和完整轨迹识别，直接预测四组短时活动概率**，而不是把“分四组”或“事件loss”当作新发现。

## 数据与目标

沿用1053拟合/199校准开发/353回归开发的固定句子划分，与clocked_residual30的来源和成员逐项绑定。199与353已反复使用，上游冻结run12全局表示也有历史曝光；结果不是独立泛化证明，不读取405或封存test。

25fps原生时间轴，32帧完整观测context，hop8，最后一窗固定贴齐完整run结尾；短于32帧的run不构造标签，报告被排除片段和帧覆盖。不得跨缺帧差分或按GT事件位置采样。目标仅使用中心8对帧变化：窗口位置11至19的9个平滑状态，平滑为各通道固定3帧等权平均（原始位置10至20），然后计算8次差分。每组活动能量为25乘差分的RMS（同时平均8对和组内通道）。组为抬眉(upper9中2,3,4)、压眉(0,1)、眯眼(5,7)、睁大(6,8)。三帧平滑只降低高频跟踪噪声，不把概率解释为真实肌肉事件。

每组阈值固定为拟合窗口能量的clip-balanced加权65%分位数，下限1e-6；目标为严格大于阈值的Bernoulli值。每片权重相同，片内每窗均分。不用查询动作均值/RMS、人物专属阈值或开发集幅度标定。报告拟合/开发各组发生率、原始/平滑能量及全零/无变化片段比例，识别目标退化。该目标表示“在动”，不区分抬起/放下的速度方向，也不是从静止转入运动的hazard。

## 条件与训练

冻结run12音频全局65维（global64+intensity1）。静态上下文为global65与原片四维prosody均值，共69维；均值/标准差仅在有完整32帧窗口的拟合片段上计算，其他拟合片段也排除于阈值和训练。静态网络69→32→SiLU→4，训练30轮。

冻结该静态网络。时序分支仅用四维prosody（1536:1540：log pitch、log RMS、periodicity、voicing），减原片有效帧均值，再除拟合帧的四维标准差，32帧均分八格得到32维描述。网络32→16→SiLU→4，末层零初始化；修正为tanh(head(descriptor))−tanh(head(0))，尺度固定1，无开发集选择。静态输入严格抵消，全局不进入修正旁路。

静态和修正分别30轮，三个预设训练seed 20260918、20260919、20260920；batch256、AdamW lr3e-4/weight_decay.01、gradnorm1。仅一个clip-balanced四组平均Brier目标，不类重加权。固定预算，不挑epoch或seed。静态阶段和对应修正阶段使用相同窗序列。保存权重、所有曲线、参数、统计、阈值、源文件哈希、成员、种子与终态。smoke仅先12片/单seed/2轮，不影响正式预算或阈值。

## 干预与判据

真实、静态、每个连续run倒序、每run循环平移一半长度、同身份同情感不同句的错配。全部保留recipient原片全局和prosody均值。错配donor必须单个连续run、长度≥32，按clip_id确定；donor动态在recipient每个完整run插值，最后整体去donor重采样均值并加recipient原均值。不得根据目标选择donor或调整时延。所有干预在相同recipient窗口上评分。静态训练基线与时序模型静态输入必须逐值一致。

主要预测为三个预设seed概率的等权ensemble，静态对照也相同ensemble。Brier按片均分、片内按窗均分、组均分；共同错配支持必须覆盖≥80%可评分片段和至少8句。按句聚类bootstrap2000次，固定seed20260918；同时报告各seed、各组、情感、身份与句子结果，BCE作为补充。

199和353均需通过：真实相对静态的Brier改善≥1%、95%区间下界>0；真实优于倒序/错配/平移且三者配对改善区间下界>0；抬眉+压眉平均同样相对静态≥1%且下界>0，两组各自不得恶化超过2%；任何一组不得恶化超过2%；共同支持的四组目标发生率各在[.05,.95]；三个单seed相对静态均有正改善。未通过就不接入生成器，不扩大轮数弥补。

通过也仅表示当前已用开发数据上的活动条件有信号。之后才能固定概率控制先验的激活/保持/释放，验证动作形状、自由生成连续性、全局情感/口型/身份；该生成阶段需另立协议并保留静态对照。最终研究结论还需要全链路未曝光的数据。
