# 开题前两点与 v5 的统一升级方案

日期：2026-10-13。状态：研究方案，尚未实现或训练；不代表新模型效果或创新性已经成立。
本文件替代同日早期 ACRF/PPEDD/CESRD 草稿，以及旧 v7 中“中性参考只能后置偏移”“投影保证口型不变”等过强表述。v5 保留为基线。本轮不使用 SSH。

## 1. 原文目标与实际基线

开题原文来自 `proposal_extracted.txt`，P 编号是 OOXML 段落序号，不能当作页码。

- P0177–P0181：研究点1是 BlendShapes 数据构建与非配对条件下的内容、情感、风格三重解耦；同人不同片段风格一致、交换重组与循环一致性。
- P0183–P0191、P0235–P0239：研究点2是视觉特征教师到音频特征学生的跨模态对齐、情感潜在分布及逐帧动态强度。
- 报告没有要求以真实动作减中性动作获得纯情感。InstanceNorm、平均池化、循环一致性或特征正交也都不能单独证明解耦。报告中的“彻底解耦”“理论证明”和上/下脸完全独立应收敛为可测的条件不变性。
- RAVDESS 改为当前 MEAD，数据补充仍使用 HDTF；保留原研究任务。CLIP 可留作后续控制扩展，不绑在本轮三个贡献中。
- 所选 `configs/current_model.json` 为 v5_matched_control/KineTalkV4Model，生成路径是 frozen B0 + joint 52D residual + rig projection；teacher_guidance_mode=none。
- 当前 teacher 的输入和辅助状态目标使用同一 query 的 `motion - b0`，时间一致，并非两条独立表演相减。该差值包含 B0 口型错误、风格、表情和追踪噪声，只能视作动作修正量。所选 v5 解码器为 TemporalEncoder+Linear52，不是 Flow Matching/DiT。旧 flow/DiT 实验不能自动计入当前 v5 的有效贡献。
- 当前 SingleReferenceStyle 输入是独立参考的原始52D motion、去均值轨迹和通道mask，经时序编码与pooling；它并未用“参考序列减去query中性序列”提取风格。该路径仍需通过跨内容/跨情感实验检查泄漏，不能将pooling视为证明。
- v6 一次改变内容瓶颈、解码头及分布处理，直接训练臂退化；其 posterior 臂未训完，不能用它否定所有视觉表征蒸馏/概率动态方案。

## 2. 采用的概念定义

### 内容 C

语音携带的发音序列及其时间结构。不是整个中性 52D 动作，也不是把所有嘴部通道固定归给内容。个人嘴部开合幅度、情绪性嘴角拉伸会改变几何，但应保持可辨认的发音和合理的音画时间关系。

### 情感 E

跨说话人共享的可见情绪语义，以及该语义在时间上的表情展开。相同 angry 在不同人上应有一致类别/相对强度意义，不必有完全相同的 BS 曲线。MEAD 标签监督类别和片段级强度；没有真实逐帧心理情感标签，不能把一条自动提取曲线称为心理情感真值。

### 风格 S

个人在发音、情绪表达等条件下相对稳定的运动响应倾向：嘴部开合/圆唇幅度、紧张/偏置、眉眼与嘴部的惯常响应比例、动作幅度和响应时序等。不是当前参考的表情，也不是脸型、头部姿态或一句话的发音轨迹。

同一个人不同情感下应共享 S，但由 S 实现出的动作会随 C/E 改变。可以让个人习惯改变“怎样表达同一种情绪”，但不能把 happy 改成 angry、把参考情绪注入查询或改变查询的语音内容。这里的解耦是因子语义/控制职责的可分离，不是要求它们在输出上毫无交互。Mimic/DiffPoseTalk 支持运动习惯这一范围；跨情感稳定的 person style 是本任务的更严格操作性定义，不宣称所有 style 文献都作此假设。

当前只输出 ARKit 52D。头部运动另需姿态输出；脸型/摄像机/拟合者差异是混杂因素，不可当成个人风格优势。

### 动态与不确定性

区分情感表达的上升、保持、衰减、局部协调，与眨眼等自发面部动态。眨眼多不等于情感动态更好。

音频对某些变化有约束，但不唯一决定一次表演。要学习条件轨迹分布，并保持类别、语音内容和个人风格。不同随机种子只证明输出可变，不证明真实或有情感。

## 3. 推荐架构：群体表情生成 + 个人条件响应

不要继续用“中性预测 + 一切未知量的联合残差”作为最终语义定义。

主模型写为：

`Y_hat = D_pop(C, E, N) + R_response(C, E, N; S)`

- D_pop 直接生成一个完整的群体规范表达，包含说话、情绪与表情时序。它不是只含口型的 neutral base。
- “规范”是模型内操作性定义：以 S 的群体先验中心（默认 S=0）定义 D_pop，通过说话人/类别均衡采样、S的中心与尺度约束和支持查询任务固定分解原点；不是一条已知的群体动作真值，也不宣称该分解具有唯一性。
- R_response 是以 C/E/局部事件为条件的个人运动响应修正，表达“相同内容与情绪下，此人怎样动”。它不是把一个参考动作逐帧减去另一条中性动作得到的输入。
- E 是逐帧的多维表情状态，不是一个固定类别向量乘一条强度曲线；N 是局部表演事件的辅助潜变量。N 不作为第四类语义控制，避免把所有自发动作强行称为情感。
- 内容、情感、风格都能影响嘴部的不同性质；最终仍统一生成全 52D，不使用按情绪类别选通道、固定嘴部屏蔽或三条硬分开的输出头。
- B0/h0 可作内容分支初始化、对照和辅助教师；不强制将其 52D 输出加到最终结果上，不要求新版保留 DESTalker 式中性基底语义。
- 重建误差中当然仍有“预测减观测”，但这是生成模型的训练误差，不被当作纯情感或纯风格标签。

### 初始容量建议（需要 pilot 校准）

- 内容：现有 768D HuBERT → 128D 时序适配器；保留高容量内容表征，避免重演无监督 24D 瓶颈。
- 情感学生：现有 768D emotion2vec + 4D prosody → 条件轨迹生成器。
- 视觉教师：原始 52D motion、有效帧/通道掩码，加上内容与个人响应上下文 → 16–24D/frame 情感轨迹及 4–8D/frame 局部事件码。不是旧 10 个手工残差轴。
- 风格：低秩 16–32D 响应系数及其后验；使用一条带音轨的参考视频。参考语句/情感无须与 query 相同，音轨用来解释参考正在发什么音，不送入 query 内容分支。无音轨时由视觉内容编码器估计上下文，置信度相应降低。
- 训练 query 先用 4–6 秒连续窗口；参考可用一条 6–10 秒片段。可调，但不能把重叠窗口数当独立数据量。
- 轨迹保留原始时钟，先不将瞬态动作降采样到低帧率。Flow 用紧凑时序 Transformer/DiT，先验证 8–16 步采样质量和速度，不把网络名当创新。

## 4. 候选贡献1：可校准的个人条件响应残差

将残差从“中性到所有表达的补偿量”改为“规范表达上的个人响应差异”，用明确的生成似然学习而非原始减法提取。

可采用低秩线性于 S、非线性于上下文的形式：

`R_response_t = B_theta(C_neighborhood, E_neighborhood, N_neighborhood) S`

邻域表示允许响应幅度/偏置及短时滞后，B 输出全 52D 的响应方向。时间偏移仅允许受语音等价约束的局部响应，不能任意移动发音时间轴。

对参考使用带观测质量权重的生成模型：

`p(Y_ref | C_ref, E_ref, N_ref, S) × p(S)`

从中估计 `q(S | ref)`，并用 disjoint query 的预测误差训练/校准后验。可先实施条件线性高斯后验：在教师估计的 C/E/N 下用响应设计矩阵 B 计算 precision 和 mean，缺乏对应上下文时 posterior 接近 population prior。后验只是在既定模型和估计上下文下的条件不确定性，不是物理真实的不确定性，也不保证覆盖校准。

关键要求：

1. 输入中的 C_ref/E_ref/N_ref 用来解释参考自己的表演，只有 S 传到 query 的风格路径。
2. 一条中性短参考可支持部分发音响应，无法唯一识别该人全部愤怒/开心的特有表达。跨情感泛化来自多人跨情感训练和先验；缺乏参考支持的部分回退群体响应。
3. 观测误差要按可靠片段或块建模，不能把相邻强相关帧全当独立证据，导致长参考虚假自信。
4. 风格训练不是只有 speaker triplet。用同人跨句/跨情感 support→query 重建，学习响应行为；身份对比只作辅助，加入参考替换稳定性、内容/情绪泄漏检查。
5. MEAD 有合法跨情感正样本；HDTF 优先用不同 source/非邻接片段的同人支持查询，且核验跨视频说话人身份。不能把同一视频近邻一致当作跨情感一致的证明。
6. 对静态脸型、拟合偏差和数据源差异做混杂检查。不只报告 speaker 分类准确率或 t-SNE。

相对于 DESTalker 的 pooled style + adaptor，此候选贡献是“有生成似然和支持范围的条件个人响应估计”。对比：普通 pooled code、相同响应结构但确定性估计、无覆盖回退、完整后验。必须证明相同参考时长下更丰富/更相关上下文带来更准确响应与合理校准，而非多加参数带来收益。

## 5. 候选贡献2：可重建视觉轨迹教师 → 音频条件轨迹生成学生

教师先学到一个有语义锚点、可通过实际解码器还原动作的视觉状态空间，再冻结/稳定它进行跨模态学习。不能重新给旧阈值事件解析器挂“教师”名称。

教师教授：

- 全局情感类别/片段级 ordinal 强度的共享表征；
- 一次真实表演中实际观察到的多维情感轨迹 E*；
- 局部动作 N* 与可靠性掩码。
- 它不把 B0 错误作为情感真值，也不从单个表演推导同一音频所有可能表演的真实分布。

默认先实现可重建的确定性运动编码器。若以后引入视觉 posterior，其方差代表观察/表征后验不确定性，必须与音频条件的一对多表演不确定性区分；无需为了保留“CVAE”名称强加一个高斯方差头。

音频学生学习：

`p_theta(E_1:T | A_affect, prosody, emotion_control)`

以及局部事件分布 `p_theta(N_1:T | A, E, S)`。E 的规范语义不由参考情绪改写；个人局部习惯可通过 S 改变事件率/幅度等，需测情感保持。

实际 flow-matching 路径：

- TRAIN 教师给出轨迹目标 X1=(E*,N*)；X0 来自高斯基础分布。
- 对 t∈[0,1]，Xt=(1-t)X0+tX1。
- 时序网络预测速度 `v_theta(Xt,t,conditions)`，匹配 X1-X0。
- E 速度分支采用音频/情感条件；N 分支还可采用 S 和 E 上下文。用结构或条件掩码限制 S 直接改变 E 语义，并用干预测试验证，而非声称掩码已证明解耦。
- 推理只给音频、所选/预测情感、独立参考和随机种子，经积分采样轨迹，再统一生成动作。前序窗口只用已生成动作上下文。
- 允许固定 emotion control 和参考时采样多种合理时序；不要求每一个 prior 样本精确对齐同一条 GT 事件。
- Teacher-conditioned 的重建可用点位/速度损失；无观测动态条件的 prior 采样不直接加同一 GT 的逐帧强 MSE。否则重新学成平均动作。

Flow 依靠多样的训练表演、条件共享和正则化估计分布；一个 query 只有一个表演时，精确同音频条件下的多模态分布不可完全辨识。需要未见说话人/内容、多采样质量-多样性和人工评估支持，而不是宣称模型知道每条音频应当何时皱眉。

逐帧强度：

- 显式强度头只是可见表情强度的监督/控制读出，不负责把全脸压成一个标量。
- MEAD level 是片段级 ordinal 标签，只约束聚合强度/同类不同 level 的排序，不能铺到每帧当真值。
- 帧级依据可用独立的图像表情/AU估计、固定 rig 可测几何及少量人工强度/起伏标注，统一记录为弱标签并按质量加权；ARKit 控制器名称不是 FACS 或心理情感标签。
- 没有可靠帧级标注时，可以报告学习到的表达轨迹和可观察动态，而不能报告逐帧情感预测准确率。
- 对 anger/happy 的形变方向、局部力度和时间演化分别检查，不让张嘴幅度冒充情感强度、眨眼冒充情感动态。

此贡献的主张是“具备语义/重建锚点的规范轨迹向音频条件分布迁移，以及因子保持的时序生成”；teacher/student、flow、DiT、onset/duration 本身均已存在。当前 v5 已有 onset/duration/amplitude，不能重复计为新设计。

## 6. 候选贡献3：语音等价约束下的反事实联合解码

不复用 v6 的硬拆输出头；保留联合生成能力，同时把解耦验证从“编码器自认纯净”扩展到输出行为约束。

训练一个独立的、跨人跨情感的 motion→viseme/content observer，冻结后用于真实/合成序列的内容一致性。可用音频识别得到的高置信时序伪标签/可见音素分组训练；它不是额外文本语义输入。可见音素存在多对一，observer 只能约束视觉内容等价，不能证明完整语音信息保持，必须配合实际同步评估。

对固定 query 的 C 和音频时间，改变情绪、强度、风格或随机种子：

- 内容 observer 的时序发音证据应保持；
- 情感改变应改变可见情绪及强度/轨迹；
- S 改变应改变个人响应统计，但保持所选情感语义；
- 随机种子改变应产生合理时序差异，保持内容、情感和个人倾向。

监督组成：

- 真实 self/support→query 重建：52D/rig 几何、velocity、高置信口唇事件与 native timing。
- 输出内容等价：真实 query 和反事实生成的 viseme evidence 一致；以教师/音频置信度加权，低置信处不硬锁。
- 情感保持：独立冻结的情感评估器 + 标签/ordinal 约束。
- 风格保持：跨参考支持查询 + 独立风格评估。
- latent swap/cycle 可辅助，但不得作为纯净解耦的充分证据。
- 任意情绪/风格交换没有对应真实帧级 GT，不能把 donor clip 直接作为其动作重建目标。仅同因素实际可匹配且时间合理的样本可有对应监督。

锁定发音职责，而不是锁定中性嘴部宽度。这样 angry 可出现更宽/更紧的嘴角和不同发音幅度，同时保留查询发音的闭合/开合时间关系。若 observer 对情感形变有偏差，损失会错误抑制表情；需要先用真实 MEAD 各情绪验证其稳定性和 false positives，再用于训练。

这是待验证的“输出层面语音等价的反事实联合约束”，不是把已有 cycle 换名。Mimic 的内容对比/循环、SubtleTalk 的控制不变性和 DiffPoseTalk 的局部音画对齐均需明确引用。若只做到普通 shared decoder + latent cycle，此点不足以成为独立创新。

## 7. 三重解耦的合法训练样本

- 风格正样本：同人、不同语句、优先不同情绪/level。训练用多片段形成 episodes，部署只需单条参考，不能将训练多片段误写成推理两条参考。
- 情感正样本：不同人、同情绪/近似 level，只约束共享语义/统计，不要求逐帧 E 或 BS 相同。
- 内容对齐：音频与该视频本身的 motion；不同表演即使文本相同，仍需时间/可见音素对齐，不能原始相减。
- 同人不同参考替换但 query 完全相同：可对同一真实 query 重建，是排除参考内容复制的强训练信号。
- 三因子 arbitrary swap：只用保持/循环/真实性约束，无虚构 framewise GT。
- HDTF 情绪 unknown：mask 分类/ordinal/cross-emotion标签损失；可做内容重建、响应 support/query、自发动态/无标签轨迹预训练。不能默认 neutral，不能将有标签与无标签片段全部 adversarial 对齐抹掉情感。
- 数据划分先按 speaker/source video 建立，再切窗；核验 MEAD/HDTF 身份重复，严格避免重叠片段和参考查询泄漏。测试说话人只允许独立 enrollment 参考，不能用测试 query 训练风格。
- MediaPipe/ARKit 是拟合得到的伪动作标注，需保留缺失通道、遮挡/转头、拟合置信、音画偏移、native clocks 和统一 shared rig。

## 8. 实施优先级和可证伪门槛

1. 先不训音频 flow。用真实动作教师的 C/E/S 输入检查联合解码器能否重建八类表情，尤其 angry 口角宽度、sad 压唇/下拉、contempt 不对称。这确定表示/解码器是否已解决 v5 的真实形状瓶颈。
2. 在同一个解码器上先训确定性音频轨迹学生，获得可比较基线；避免将新增表示、style posterior、flow 和多个损失同时改动，无法定位成败。
3. 加入 conditional trajectory flow，比较潜空间 flow 与相同容量的 52D residual flow、CVAE/确定性学生及 current v5 event sampler。以 held-out 统计/动作质量-多样性曲线评价不确定性。
4. 单独加入 response posterior/coverage 回退与输出反事实内容约束。每项都有同预算、同数据、同解码容量控制和消融。
5. 使用 fixed development protocol、多训练种子和 paired speaker/source bootstrap；v5 始终保留，不按两条好看的视频挑模型。

验收表：

| 目标 | 主证据 | 不能替代的证据 |
|---|---|---|
| 内容口型 | 同 rig LVE、闭合/同步时间、viseme error及 native 视频 | 仅全脸MSE或只有B0嘴部 |
| 情感 | 8类/各level的独立motion与render/image probe、人工类别/强度评估、angry宽度等几何 | 学生自己的分类准确率、t-SNE |
| 情感动态 | 有标注/可靠弱标注子集的强度排序/起伏、attack/hold/relax统计、局部协同、人工时序自然度 | 眨眼率、噪声导致的高方差 |
| 自发动态 | 事件频率/间隔/时长/幅度、速度/频谱分布、sample质量-多样性 | 每个sample对唯一GT的事件F1 |
| 风格 | held-out跨情绪同人检索、不同参考/不同句子的响应预测、SCS/MOD/LDD原定义或明确改造版、out-of-support校准 | speaker分类、数据源识别、同一生成器embedding自评 |
| 解耦 | 固定音频下的emotion/style/seed因素实验，同时量化目标变化与非目标泄漏 | 名字不同的编码器、全局pooling、单独cycle |

暂定 promotion gate：配对 bootstrap 下口型/同步至少不劣于 v5（提前制定实际非劣效界限）；主要薄弱情绪的可见形状/情感指标改善；情感动态与风格各有独立正证据；三个模块各自存在可重复消融收益。设计阶段不能承诺越过这些门槛。

## 9. 文献边界与引用

本轮阅读本地六篇 primary source 的方法段落，避免把其他阶段AI总结当论据。这里是有限文献范围内的差异，不是全领域首创性证明。

| 文献 | 已有内容 | 本方案需要新增并验证的部分 |
|---|---|---|
| DESTalker，§3.1–3.5，doi:10.1002/cav.70127 | neutral base +统一residual；global emotion/style；同人跨情感MI/正交；EAM/SAM | population完整表达 + 有似然/覆盖的个人条件响应；不是仅添跨情感positive |

DESTalker 原文确实宣称 pooling 丢弃 temporal linguistic content，但 pooling 并不能从数学上消除内容：音素比例、均值开口、节奏仍可能携带内容。不能将其论文的表述当成无需验证的保证。

报告 P0262 将 EVE 称为情感自然度，应改正：几何 EVE 是区域形状误差，不是心理情绪准确率或动态自然度。各论文的 FLAME/ARKit、单位、rig、数据不同，原表数值不能直接拿来当本模型优势。

三个点目前是具体、可实施、可证伪的贡献候选。只有完成针对性近邻查新与同预算消融后，才能确定为三个独立创新；不能靠换名字或保证“肯定比v5好”写论文。
