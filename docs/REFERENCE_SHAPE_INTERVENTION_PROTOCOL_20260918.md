# 独立参考时间形状干预：最小诊断方案

2026-09-18。**状态：proposal，尚未实施，尚未生成对照或开展新训练。** 本文提出一次有界诊断，不承诺下一轮能够成功，不替代已有失败记录，不以新名称重复训练既有运动先验。默认权重、身份/情感/口型基座及原始训练清单保持不变。

## 要回答的问题

第三版教师的阶段识别覆盖为抬眉6.84%、压眉3.94%，说明当前监督不足以支持完整四阶段动作及等待时间模型；这不能推出连续运动轨迹没有学习价值。像素光流96.89%的可观测比例也不等于真实眉动作获得认证。两项结果都不宜直接用作所有运动模型的训练许可或禁止条件。

本试验只问：**在静态眉形与渲染通路相同的条件下，独立真实参考的联合时间形状，是否比保留二阶统计而打乱时间形状的替代轨迹更自然？** 若连真实参考形状搬运都不能给出可见、合理的眉部变化，应先修复表示、静态与动态组合或渲染传递，暂不投入新先验训练。

这里的“时间形状”包括局部起伏的不对称性、短时间形态及高阶时间关系，不等同于已被人工认证的起势、保持、回落语义。

## 与已做方案的区别

- `motion_process30`已经验证可变线段重构，但局部音频似然和自由生成失败；约7个控制段/秒不是动作语义。本试验不再拟合线段持续时间或方向。
- `native_context30`及Temporal/Centered/PrefixUpperFlow已经使用随机轨迹生成与上下文；再换TCN或重新训练整段global flow不能单独构成新假设。本试验不新增flow或音频头。
- `joint_prior_formal30`与clocked系列已有联合形状/全局条件先验；工程门槛或分布评分不等于感知自然度，局部音频时机增益仍未通过。本试验不重新命名medoid或重跑同样分类器。
- 连续Matérn方案把参考压为RMS与tau，未证明自然度改善。本试验首先隔离**保留参考时间形状与仅保留二阶统计**的差别，Matérn只作辅助历史对照。
- 稀疏事件方案因真实完整事件和等待监督不足而未拟合。本试验不用四阶段标签、不把未知区域当静止，也不要求一个短片包含完整动作。

## 元数据固定的8对样本

只使用既有1053 fit池的授权来源；不索引或读取405与封存test。预设四人M003、M005、W011、W014，各取angry、happy两个情感，共8个固定单元。每单元按`clip_id`字典序取第一条符合数据完整性要求的query，再取同人同情感、不同句的第一条reference；跨单元不复用片段。

在读取动作值或观看视频前保存pair manifest、来源ID、句子ID、视频哈希、完整性规则与代码哈希。只允许用元数据、可用文件及原生有效mask确认是否有足够长度；不得依据动作幅度、阶段数量、相关性或可见效果选片。缺少合格单元就报告缺失，不临时换人物或情感。

两端都排除本轮反复检查的32片，以及既有固定32个controlled-prior query/reference列表中的片段；这些排除列表的实际来源与哈希须写入manifest。不把同一32片重新包装为新验证。若排除后不能组成8对，则保留不足8对的事实。

reference使用与本轮审计一致的fresh-reset提取配置、有效mask和原生25Hz时钟；保留raw与SG5/2副本。每条只用第一个满足至少50个有效内帧的连续run，首尾各留2帧SG保护；query和reference均从选定run首有效内帧起，取共同长度`T=min(T_query,T_reference)`。不伸缩时钟、不循环、不拼接缺口。T由元数据/支持范围决定，不由动作内容决定。

这些样本仍来自历史fit来源，冻结上游模型可能见过它们；排除32片并不建立全系统未见数据。8对只是新的机制诊断，不足以报告泛化、论文级质量或人口总体结论。

## 三个对照臂

所有臂使用相同query音频、冻结模型、独立中性身份anchor和输出长度。query静态眉level使用现有冻结global预测，先记录其原始值和物理域有效性；不读取query真实眉形、均值、端点或动作历史来校准。只覆盖5个眉通道，其余47个52维系数逐值复制同一冻结完整面部基线。

**A：独立参考形状搬运。** 取reference的5维SG5/2眉轨迹，减去该共同长度窗口的reference均值，得到联合残差`r_A[T,5]`。输出`level + gain*r_A`，首版固定`gain=1`。参考均值不搬到query；不使用query运动确定gain。本臂是允许额外表达参考时的**诊断上限/正对照**，不是最优性能的数学上界，也不是训练出的先验。

**B：二阶统计保持的时间形状破坏。** 对A的5维残差作实数FFT。每个非DC、非Nyquist频率独立采样一个相位，对该频率的全部5通道施加同一个相位；DC保持0，偶数长度的Nyquist项保持原值，逆变换回原长度。不再次平滑、不排序幅度、不按生成结果重新归一化。在线性系数残差域内，该操作保持各通道功率谱、RMS及完整交叉谱，改变高阶时间结构及局部形状；它并不保证保留原始值域、有限窗口边缘行为、非循环差分统计或语义动作。

B的相位种子固定为`42,123,2026,7,19,73,211,997`，全部保存与评估，不挑最好种子。它可能因有限片长产生明显边缘效应，必须单独报告，不能自动把全部差异归因于自然动作结构。

**C：既有RMS/tau Matérn。** 使用已冻结连续过程的实现和参数估计规则，从同一独立reference提取部署可得的条件，以同一query level及固定gain生成，再取其5个眉输出，其他47通道仍复制共同基线。种子与B相同。原Matérn的logit变换和有界解码不同于A/B的线性组合；因此C是历史方法对照，**A与C的差别不能唯一归因于时间形状**，主要因果比较是A/B。

reference轨迹及其均值只属于部署时额外输入，不是query GT泄漏；但直接搬运轨迹必须明确展示，不能称其学会了条件分布、独立生成动作或由audio预测时机。

## 必须在实际输出之后重新检查

先保存原始残差、组合后的未裁剪系数和最终送入渲染器的系数，逐层绑定哈希。A/B的理论频谱性质只适用于上述线性操作，不能越过clip、sigmoid、非线性重映射或隐藏renderer clamp直接沿用。

至少重算以下量：

- A/B残差及实际5维输出的各通道RMS、均值、功率谱和交叉谱；同时给出非循环速度/加速度和片首尾边缘统计。共享常量level本身不改变非DC谱，但所有实测结果仍须报告。
- 原始level及组合输出的越界帧/值比例、最大越界幅度、上下边界占比；各人物分别列出。
- renderer输入到实际显示路径是否发生裁剪或其他变换；重算变换后的幅度和频谱变化，并报告幅度保留率。
- 其他47通道与基座逐值相等、输出时钟一致、不跨缺失run，且没有query运动参与生成或缩放。

**超界不得静默clip，也不得看结果后缩小gain、换片或换seed以通过。** 非法系数保留为失败结果，不自动送入依赖物理值域的正常质量比较。如果需要另做显式clamp显示，只能作为有清晰标签的辅助诊断，必须保存前后结果；一旦裁剪破坏二阶匹配，不能再把感知差异解释成单独的高阶时间形状效应。共享level本身非法时，同样报告组合前问题，不用GT替换。

## 固定产物与判断边界

先交付全部8对的曲线和对应原视频，主视频固定展示A、B-seed42、C-seed42及冻结基线；其余种子完整保留并提供同口径播放入口。不能根据画面更换主种子。所有方法采用相同镜头、帧率、几何身份、画面尺寸和音轨。

原视频与A的对应用于检查表示/渲染是否承载可见眉运动；A/B匿名随机左右排序可用于配对自然度判断。没有独立评审者时，助手目视只能记为探索观察，不能称盲评已通过。音轨可用于观察口型保留，但本试验的参考运动与query音频没有时间对齐要求，不报告音频同步成功。

决策仅有以下三种，不追加同轮参数搜索：

1. **A也没有可见、合理的眉变化，或输出频繁越界/被裁剪：** 先处理监督到系数、静态组合或渲染传递；本试验不支持新先验训练。A失败也不能直接证明参考原视频无眉动作。
2. **A优于B且差异不能由越界、裁剪或边缘退化解释：** 支持进一步研究保留局部联合时间形状的运动表示。A优于C只能作补充，不能替代A/B控制。仍须设计独立学习及自由生成检验，不能从搬运成功跳到生成成功。
3. **A/B相近或B更好：** 本组证据不支持“高阶时间形状丢失”是主要缺口；不要为此直接增加模型或训练轮次。8对阴性结果也不足以证明所有形状先验无效。

使用真实目标端点或边界的重构只能证明表示可拟合目标；A只能证明独立参考轨迹可经过当前通路执行。二者都不证明音频可预测动作时机。其余47通道数值保护也不替代身份、情感、口型和眉眼协调的独立感知验收。

本试验仅覆盖短原生有效run，不循环、不自动拼接；**长序列持续生成、状态续接、动作多样性和语音驱动时机均未解决。** 本文没有规定新训练轮数，也没有启动后台训练。
