# 训练集尺度定标：8轮单因素对照

2026-09-16，结果前记录。上一轮中心化目标改善上脸但眉毛仍失败；同clock拆分：audio直接眉毛R²+.03133，GT rank8投影+.31078，生成audio−.08298、生成oracle+.12834，zero生成−.08663。低频有信号但传递损失明显；全帧眉毛仍退化，不等于简单增幅可解。

损失尺度也不均衡：旧生成centered嘴部SSE约眉毛27倍；RRR所选基主要覆盖嘴部。这些是诊断，不证明唯一因果。本轮只检验生成loss尺度，不同时修改RRR基、音频预测器或生成结构。

两个真实arm：uniform与train_rms。相同data_locked 19人2315fit/3人405dev、seed46、batch16、Adam .0002、8epoch共1160步、持续teacher .5、12步rollout；原512参数投影零初始化，所有其他模块及rank8基冻结。两个arm随机batch/noise/time/teacher draws逐轮匹配。uniform应复现上一轮epoch8日志指标，补齐其当时未保存的权重与四模式曲线。

唯一干预：只从19人训练的`center(target-B0-id)`计算每个observed通道RMS。统一floor为observed正RMS中位数，`w_c=1/max(RMS_c,floor)^2`，归一化到observed通道权重均值1。单一loss变为`mean_observed(w_c*(center(pred-target)/residual_scale)^2)`。不按区域手调、不用dev定尺度、不放大低方差通道到无限、不加第二loss；预测输出保持原值。该度量只改变训练关注度，不改变评估的原始单位。

固定epoch8主比较，epoch2辅助，不挑best。两组都保存原始full/zero/reverse/oracle×3noise。评估同组zero/反转、眉眼逐人、neutral原动作/嘴部相关、速度与全局读出、非neutral均值误差，句簇bootstrap5000。比uniform好但仍不如zero不能算成功。未动外部280/439或最终test；405是已有内部开发，非独立最终证据。

若眉毛仍失败则保留默认，不继续堆训练。8轮预算是用户明确偏好；本轮不用18轮。结果待测。
