# 论文实验数据整理协议（开发集）

2026-09-19，用户授权主指标、消融、整理与并行动态优化。此协议在本轮新增指标计算前固定；沿用已完成有界适配运行，不据新增分数选模型。

数据为bounded_audio_formal24000的64条历史外层诊断、7句、所有固定4seed。当前模型默认未替换，有界audio的内层验收失败。报告使用“development diagnostics”，不能写成最终封存测试或未知身份泛化。613训练/206内层验证用于先验及适配，继承上游已有历史曝光；本轮不启动封存测试。

## 同批次主表与消融

冻结基座、全局条件先验、有界audio、同模型static/reverse/mismatch、配对静态训练。基座确定性一次，随机模型四次取逐次指标均值，禁止先平均生成轨迹或挑最佳种子。按clip等权汇总；句子簇bootstrap4096次、固定seed20260919给95%内部描述区间。报告每情感、每身份分组，不以最好子组代替整体。

ARKit52系数指标（原始值，不裁剪、不放大、不拟合时差）：lip controls18:41的MAE，jaw+mouth14:41的MAE/RMSE，upper9=[41,42,43,44,45,5,6,12,13]的MAE/RMSE，全52 MAE，嘴部/upper9速度MAE（系数/秒），upper9逐通道std绝对差与有符号GT−pred差（ddof0），逐帧mean(abs(upper9))强度MAE，upper9逐样本间RMS距离。绝对std差越低越好；有符号差接近0，不标单调越低越好。强度是运动系数代理，不称心理情绪强度。

审计后使用原始数据集target52、valid、channel_mask计算，NPZ仅提供各方法预测并逐一核对时钟、基座和已观测参考；显示填充值不参与参考。所有方法使用同一参考、时钟、支持与基座，记录SHA256。std在该通道所有观测帧计算；速度只跨相邻原生有效帧，不跨缺口。误差按每片支持元素平均，RMSE先每片/每draw取根后汇总。95%区间反映有限开发片段，不代表论文显著性。

沿用分布fair ES、variogram、速度与幅度比等固定定义；另算基座分数便于配对对照。系数代理不能直接称MetaHuman MLE/MEE/EIE/FRD或FLAME LVE/FDD，更不能把本文系数数值与原文表直接拼接排名。参考映射见PAPER_METRIC_SOURCE_MAP_20260919.md。

## 情感、身份、口型证据

独立真实动作统计探针可补充情感识别及说话人动作特征保留，必须公开真实动作验证集表现，严禁当作人类主观Emotion Acc或外观身份。继承训练教师的情感/身份评分单独列历史内部一致性。SyncNet/人脸识别对统一通用rig不能认证真人口型同步或身份。当前无公开同数据同表示基线复现，因此主表只含本方法各配置及原基座。

## 平行动作优化

独立可预测性probe只用原819训练池的613/206划分，固定0.4/1/2秒窗口与静态对照，研究动作活动/方向条件是否可跨句预测。它不使用上述64条目标训练/调参，也不改变论文评估候选。未通过前不将条件接入生成器，不以oracle接收成功替代音频预测收益。

本轮原始掩码复核修正7737个valid帧上的未观测通道值。主要口部和upper9数值保持一致，全52按正确支持重算。基座分布ES以相同确定性轨迹重复两次作为退化分布计算，spread=0，并非两个独立随机draw。
