# v5 恢复与动态修复：实际代码和证据

更新：2026-10-13。此文记录已实现内容，不是创新成立或论文效果承诺。

## 保留的有效基线

有效 v5 是 `KineTalkV4Model` 的联合生成版本，checkpoint 为
`/root/kinetalk_v5_20261012_dual/runs/control/final.pt`，SHA256：
`372dbc2a23913743cb67452bf6f5756e3be195f81c468f2a1f972afbb79c9add`。

输出仍为：

\[
Y_{v5}=\Pi_{rig}[B_0(C)+R_{joint}(C,E,S,V)]
\]

这是条件联合动作校正，不能把 `R_joint` 直接命名为纯情感残差。
查询 B0 与查询自身音频对齐；没有拿不同内容的 neutral 动作逐帧相减来构造情感标签。
内容、情感和风格仍共同进入全脸生成，没有硬切嘴部与情感输出通道。

## 本轮改了什么

1. 视觉教师：真实查询动作、查询自己的 B0/h0 和冻结音频先验，输入观察编码器，
   得到原 10D 状态坐标里的有界校正，以及情感/强度读出校正。
   校正初值为零，使用真实重建训练。旧事件分支 hidden 仍来自音频。
   教师重建有效不等于其坐标已实现纯情感/身份解耦。
2. 状态 flow：拟合 `(教师状态 − 音频状态) / TRAIN_scale` 的条件分布。
   条件为音频 hidden、情感概率和强度；不读取风格。推理只读音频和独立参考。
   随机样本不以唯一观察轨迹作为逐帧动作重建目标。
3. 参考上下文校正：在冻结旧风格码上增加全局校正，使用参考自己的动作、h0、
   音频情感先验。训练用同人异句异情绪两个支持，推理一次一条参考。
   旧风格路径仍保留，因此不能声称参考内容/情绪泄漏已消除。
4. 个人响应场：低秩全脸响应 `R_personal(C,E;S)`，零输出初始化，放在 rig 之后。
   pilot_b 没有净重建收益，后续 flow 对照两组均关闭它。没有把它当作已成功贡献。

早期 smoke_c 同时解冻 decoder/style/emotion-to-state，出现情感退化；后续已冻结这些
路径。它是有证据支持的解释，尚无单变量消融证明是退化的唯一原因。
新模块零初始化保证起点严格等价 v5，不能保证训练后的行为不发生变化。

训练和评估共191.4s；四个冻结情感探针只用于训练完成后的评估。
数值为准确率，不是历史全开发集 macro-F1。

## 当前单变量短训：flow_cov_c

共同起点：pilot_b/repair.pt，SHA256
`8bb9bfba2c3f6a74c07f69f1a6539e5c1fe198c6fca53323c75bcfab99a1b938`。
保留此文件与此前源码快照。

白噪声、时间相关 Gaussian 两组各256次，仅更新 flow。
相同批次、训练随机种子、优化器和学习率；所有非 flow state 的 digest 完成后必须相同。
教师、目标、音频语义读出、decoder、事件与参考编码器均不更新。
两组统一关闭无收益的个人响应场，另保留冻结起点用于对照。

相关基分布采用长度9 raised-cosine 线性滤波，并以权重平方和开根号归一化，
保持每帧边际方差为1。每段合法 native25fps 连续窗口单独处理，不跨无效帧或时间跳变。
训练和推理使用同一基分布。教师 endpoint 和最后动作没有被平滑。
这属于已知 flow 基分布选择，不能单独当作原创贡献。

验收还需要相同查询的多 seed 分布、情感与口型保持、风格参考更换后的内容/情绪保持，
以及真实风格统计迁移。动态差异或风格码可分，均不能直接代替这些效果。
HDTF 语义未知，情感和强度监督明确 mask；其 same-source 支持不能证明跨情绪风格。

## 完成的 flow_cov_c/d 结果与决定

flow_cov_c 两臂共70.69s。flow_cov_d 加入50%独立白噪声+50%相关噪声（方差权重），
三臂共94.90s，训练与采样使用同一个混合基分布，17项本地/远程测试通过。
c/d 的白噪声和全相关噪声结果相同，非 flow 权重 digest 均通过。

|版本|留句采样嘴部MAE|留句采样加速度/GT|未见人采样嘴部MAE|未见人采样加速度/GT|

|白噪声追加256步|.03899|1.379|.04315|1.703|

留句 flow 校正邻帧RMS：白 .22981、相关 .06657、混合 .18579；教师 .04114。
相关噪声减少高频变化是单变量结果，但采样嘴部误差没有改善，未见人四个情感探针
全相关臂 .833/.833/.833/.792，冻结起点 .875/.833/.917/.875。
均值路径各臂严格一致，这是固定权重检查，不是新模型情感提升证据。

风格交换保持原情感预测的比例（四探针）留句 .750/.641/.719/.625，未见人
.875/.792/.917/.875。交换结果没有逐帧 GT，此比例衡量预测稳定性，不等于真实情感准确率。
它表明旧风格码仍泄漏/干扰情感，不可宣布三重解耦成功。

**决定：所有新随机臂均不晋级，不开长训，保留有效v5。**
后续应先分离可预测情感趋势与不确定的局部轨迹，给随机路径添加输出层语义/发音保持验收；
风格则须独立训练跨情绪参考不变性及输出保持，不能只靠同人码靠近或身份对比。
这些是待验证方向，尚未作为有效模块实现。
