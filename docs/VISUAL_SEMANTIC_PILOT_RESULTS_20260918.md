# 视觉语义条件：当晚六臂实测

2026-09-18。已实际完成视觉教师提取、音频学生拟合和六臂30轮生成训练，替代前序文档中的“未实施”。当前结论：生成有变化，但30轮输出高频运动过强，不接受为自然动态成功。默认权重未替换。

## 数据、计算与保护

192训练/64句子隔离留出，来自历史fit池；上游曾曝光这些来源，因此只是内部开发诊断。256片共5807个5Hz视觉采样完成。冻结官方EmotiEffLib教师输出VA和8类软概率。教师未校准，轻微裁框变化可影响读出，不能称情感真值。协议见[固定协议](VISUAL_SEMANTIC_PILOT_PROTOCOL_20260918.md)。

各臂30epoch、每epoch12更新，共360步，约14万参数；六臂训练及评价共144.86秒。缓存特征使小试很快，不等同完整系统训练。六臂初始化、顺序和噪声流一致，checkpoint/源码/17项manifest哈希已核对。只生成upper9，其余43个通道与冻结run12基座逐值相同；全局和身份模块本轮不训练，motion-to-audio教师关系保留在原模型，不是在线继续蒸馏。

## 30轮终点

64留句clip等权fair ES越小越好，速度为训练尺度归一后9维一阶差分RMS与参考之比。

独立NumPy实现重算主要ES、动态能量和速度，与提交报告最大差8.9e-16。其它指标使用共享评分器复算，不能称全部独立实现。逆序条件只保存了评分、没有曲线，不称独立复核了逆序输出。

新分支相对冻结基座(raw0.527168/centered0.267070)有下降，但高频尖峰严重；ES下降不认证自然度。同预算VA动态比静态centered小幅降低约1.3%，8句等权bootstrap差值-0.002460，区间[-0.004114,-0.000984]；该区间只反映单次训练、内部8句诊断，不代表外部泛化或多训练种子可靠性。类别软概率centered差的区间跨0。语义变化不是已被证明无效，也没有足够收益支撑“动态已解决”。

音频学生的独立64留句：VA raw MSE动态0.07219/静态0.10415，但centered0.01921/0.01663；软概率raw Brier0.23020/0.28066，但centered0.07181/0.05697。即整体情感水平改善，逐片内部变化预测仍弱于静态参照。

固定四例六格预览：`artifacts/visual_semantics_20260918/experiment_v1/review_preview/index.html`。各情感按clip ID第一条，seed42，无效果挑片；neutral/happy最多96帧，其余全长，全部原生曲线保留。参考格是目标upper9+基座43，并非全脸GT。新眉通道无显示截幅；基座的部分保护通道本身越界，视频会显示截幅，不能借此声称口型/身份/全局情感全部验收。

## 固定300轮欠拟合诊断

30轮loss最后仍显著下降，且所有语义来源均有相似高频残留。追加**一次**同配置从相同初始化训练的固定300轮/3600步对照，保持同数据、条件、六臂和seed，不加loss、不平滑输出、不筛选checkpoint。它是看到30轮结果后的探索，不冒充预注册确认试验。2026-09-18 22:44启动，PID5720，远端`experiment_v1/six_arm300`；六臂已全部完成，耗时601.80秒。

VA音频相对30轮centered ES下降13.03%，软概率音频下降13.45%，均明显减少高频残留。训练预算不足确实是本轮30轮失败的一部分，但不能解释音频语义时序弱的问题。300轮动态相对各自static的centered优势分别只有0.163%和0.613%，raw优势9%/14%主要不能拿来证明逐帧时序学成。

同权重逆序条件诊断中，视觉oracle的centered ES分别从0.157014升至0.170382、0.164186升至0.184605；音频VA反而从0.163727略降至0.162586，软概率音频从0.167016略升至0.167365。说明生成器开始利用真实视觉语义的时间顺序，但音频学生尚未稳定提供正确时间信息。这里仍是单训练种子的内部开发诊断，不称因果证明，逆序曲线尚未保存独立复算。

音频分支四组动态RMS/参考：VA为[0.671,1.594,1.139,1.139]，软概率为[0.685,1.466,1.104,1.298]（抬眉、压眉、眯眼、睁眼）。抬眉不足而压眉偏大，速度仍高于参考，未达到自然动态验收。四段300轮视频及完整曲线已生成：`artifacts/visual_semantics_20260918/experiment_v1/review_preview300/index.html`，同片、同seed、同渲染协议，未作输出平滑。

300轮完整权重/预测备份已下载，压缩包SHA256 `512767ec116acc83d3bc80e711d266447707fb58f4abb9794e42f466880a8931`；17项manifest全部匹配，六臂300轮/3600更新、训练顺序和噪声流一致，主要指标独立重算通过。针对本轮实现77项测试、独立审计5项测试通过，未把历史整仓测试的已知数值敏感失败隐藏为全绿。

300轮独立主要指标最大重算差2.3e-16。按8句等权bootstrap（区别于主表clip等权），音频减静态centered ES的VA均值+0.000082、95%区间[-0.002701,0.002825]，软概率均值+0.000840、区间[-0.005967,0.008076]。均跨0，不能宣称稳健的动态条件收益。软概率raw均值差-0.069373、区间[-0.104717,-0.035439]，支持整体水平收益，但不替代时序收益。

四固定例另外复核：VA音频一阶RMS从30轮0.110–0.129降为300轮0.025–0.034，二阶从0.186–0.236降为0.035–0.060；参考二阶0.009–0.021。仍保留数十帧起落，故并非纯粹整体缩幅。四例一阶变化相关-0.127至0.126，尚未证明起落时机正确。8条视频音频绑定及保护通道均通过，复核文件为`review_preview300/temporal_30_vs_300_review.json`。

下一步重点转向音频到语义的时序学习：保留全局情感均值支路，学习相对于整段状态的短时变化，明确比较冻结均值、正常顺序、逆序和同情感错配。候选为多尺度声学时序模型，先在相同句子OOF协议中胜过静态，再用冻结300轮接收器做同噪声控制诊断；替换输入引发的分布偏移要单列，后续匹配训练单列。此修正尚未实现，不再把多加生成器轮次当作解决学生不足的手段。

当前监督仍有用途：真实视觉语义时序对接收端有实测信息，但其音频可预测部分需要单独证明。VA或类别概率都不能唯一决定抬眉/压眉、起落时刻；完整动作分布仍由运动训练目标学习。今天拿到了实际可审阅的动态实验和降抖收益，尚未拿到论文级自然动态成功。
