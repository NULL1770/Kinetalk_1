# 稀疏眉部事件：首次实现协议

2026-09-18，用户授权实施。此协议在新事件教师输出前固定；前版连续先验结果保持不变。本轮是独立表达参考驱动的眉部机制实验，不宣称音频时机学习、独立测试泛化或自然度通过。

## 范围与输入

首先使用既有元数据锁定的32片fit原视频及其隔离fresh_forward raw sidecar，原始数据不改。只提取5个眉通道：downLeft/downRight/innerUp/outerUpLeft/outerUpRight。眼部不进入事件拟合。sidecar来自同一MediaPipe，重提可复现不代表真值；独立任务在看事件曲线前先看固定16片原像素，保存助手视觉观察，不能冒充人工盲评。

教师逐有效run做SG5/2，首尾各2帧不得产生完整事件边界。两组raise=(2,3,4)、down=(0,1)，组平均的正峰/负峰均可候选。阈值固定为max(0.035,6×fit中raw−smooth残差MAD噪声代理)，不使用query归一化。按prominence识别候选，在两侧寻找4帧低变化支撑：位于峰prominence底部10%区间且极差≤阈值的0.25。起势/回落各至少4帧；重叠或没有4帧安静间隔者记复合；同时两组仅在四个边界均相差≤2帧时合并。所有短脉冲、复合、缺支撑与删失保留统计，不得丢弃后称监督完整。该明确规则取代前设计文档的未定速度双阈值方案，并在运行前声明。

32片数据小且多数表情可能已在片头形成。完整事件少不代表原视频没有表情，也不应靠放宽阈值制造训练样本。若提取与像素明显不符或只覆盖少数波动，则先报告表示/监督缺口，不训练正式概率先验。实现和合成工程验证可以继续。

## 最小概率模型与生成器

拟合前检查至少8个完整事件、来自至少4片，且raise/down支持分别报告；这个最低数目仅允许小样本工程试验，不能证明有足够统计/语义覆盖。K=min(8,max(1,floor(N/16)))；固定20次Student-t EM，自由度5，共享维度缩放，协方差0.2对角收缩与正定下限，逐clip等权。样本不足不能以重采样伪增N。

13维联合标记为5维原始系数峰值相对起点、5维终态相对该事件起点，以及log起势帧数、log1p峰平台帧数、log回落帧数。在首次拟合前明确修正原proposal的logit幅度表示：前轮M003靠近零的level会压缩固定logit偏移，因此本轮在系数空间转移事件幅度，再将目标端点变换为logit做C2插值；裁剪数量必须报告，不使用query GT缩放。部署峰值相对实际当前状态、终态相对冻结独立level，避免终态积累成随机游走；这项再锚定是生成假设，单独报告曲线重构误差。HOLD无逐帧创新。

等待表在半秒年龄桶统计风险并保留删失，不能把未知/不支持的区间当作真实HOLD。仅使用已知起点的supported_hold，右删失提供暴露、左删失不进普通等待似然；扣除确定的4帧最短保持后以每帧(终止数+0.5)/(暴露数+25)估计风险，再变成半秒桶条件概率。至少4次已知结束的等待才允许称拟合等待表。若等待观察不够，显式标注工程固定等待对照，不冒称学到自然节律。活动与幅度为不同控制：activity仅改变等待，amplitude只缩放幅度。事件序号的等待/方向随机流独立；固定seed下幅度变化不改变事件时机，activity改变不改变同序号标记。

参考只允许query外、异句fit片段的事件幅度与HOLD比例；不足两完整事件的组回退总体统计，并报告回退率。不输入query motion、参考平均姿态或轨迹。全局情感和身份level沿用已保存的v2冻结预测，不重新拟合。八个seed仍为42/123/2026/77/91/301/509/997。不得按效果选seed。

## 验证与交付

有条件继续拟合时，沿用前版32个预锁开发query，先显示每个人×情感第一条16段；全脸只替换5个眉通道，其余47通道与既有run12逐值一致、无效帧不变。也报告眉5分布与动作计数、完整生命周期、等待、峰值、持续时间、HOLD占比、60秒延拓以及控制边界；固定幅度0/.5/1/1.5及活动.5/1/2。不得以HOLD比例好看取代原像素与渲染检查。

测试包括静止与单帧尖峰无事件、有效run不跨gap、已知合成完整动作的提取、任意分块一致、序列化续接、命令中断C2衔接、参考只影响未来、幅度时钟不变、眼4静态、释放回level、60秒不漂移。单独保留每项失败，不根据当前结果反复调提取阈值。

人工盲评尚无，因此即使机制通过最多称可见动作候选；独立感知自然度和随音频动态均待验证。原405/test不读、旧24539实例不碰、默认模型不替换。

## 首次运行后的纠错记录（保留v1，不冒充预注册结果）

v1仅2事件，但审计显示完整左右支撑候选本有53个，复合门后16个，其中14个被“缺支撑候选扩展至run边界”的重叠否决规则删除。这是过度保守的冲突定义，不是原视频只有2个动作。单列`extract_brow_events_v2.py`纠正：缺支撑候选不否决完整候选、只在相同组的完整候选之间检查复合、异组可各自保留，原prominence与静止/起落阈值不变。v2得到20个事件/16片，覆盖22.6%平滑差分能量；这是提取覆盖变化，不是感知质量提升证据。异组重叠仍不能直接当独立完整5维标记训练单事件模型。

两版均没有满足等待拟合条件：v2已知起点且已知自然终点的可靠等待为0，仅2段右删失。当前完整事件监督和活动节律均未验收，正式先验不拟合，不虚构长训练任务。生成器可另做明确标为手工参数的工程控制演示：固定抬眉/压眉峰值、固定阶段长度和预设等待，证明接口与渲染可工作，不将演示冒充数据学到的动态。
