## 依据与有限假设

Phase45-u 全开发集眉部 MSE 中约 97% 来自平均偏差；音频情感头 F1 .880874，但 prior MBE .827171，GT posterior oracle .237236。固定96条的参考 A/B/聚合 MBE .835052/.872776/.858499，jaw 范围 .125797/.156529/.151296。A 的较低误差伴随幅度更小，不能直接改用 A。GT 的主动作统计 probe F1 .660344；生成 .709448 不能作为动作优于 GT 的证据。

假设：当前低维风格条件和非线性接收器未充分表达参考人物的基础姿态与情感均值。只检验一个 clip-constant 接收端修正，保持已有动态条件/时钟/原始位移；不宣称修正能解决全部动态或因果解耦。

## 预定对照与训练

固定 Phase45-u 的全部参数、B0、g/u、style、语义头及原预测。两组都拟合原预测与真实 TRAIN 动作的逐片段平均误差，各片段等权、仅观察通道、按已有 TRAIN scales 归一化。共同采用固定 ridge=.001，无超参数扫描。

- latent 控制：g32 + style64 → 52D 常量修正，共 5,044 个仿射系数。
- reference 候选：同上 + 两段独立中性参考的 residual 均值52 + 预测情感概率8 × 参考均值52，共 29,380 个仿射系数。各参考等权，缺失通道不参与；是不同容量的参考特征消融，不冒充等参数实验。

输出为原始预测加常量修正，全嘴通道开放。student 仍只有 emotion2vec768+prosody4；motion 监督仅用于拟合接收端常量映射，不更新学生。身份不查表；推理只有音频、冻结 B0、独立参考，无 query GT、真情感标签。参考侧 B0 只用于残差坐标。

该模块只能直接修正均值：raw centered trajectory、相邻位移和 q90-q10 不变；原有 clip[0,1] 后可能改变边界、闭嘴和幅度，必须实测。它不是全动态改进，也不是改变指标定义的后处理。GT/emotion probe 不用于其目标。继承父模型24 epochs/16368 updates以及一次 TRAIN解析u拟合，本轮追加两次不同特征的固定 TRAIN均值 ridge solve。

## 验收与顺序

1. 本地针对性测试：参考等权/排列/缺失/NaN、仿射恢复、未观察通道、raw位移不变、无GT部署签名、detach、保存恢复。
2. 远端真实数据 smoke：TRAIN16拟合、两内部留出各16；content/HuBERT NaN隔离、冻结状态逐位不变、所有输出有限。
3. fit 10903；原内部held-speaker743、held-sentence890，仅该两留出比较 parent/latent/reference 的原 raw/clip 系数、几何、幅度/动态、四probe、每身份。外部1367和sealed不参与拟合/调参。
4. 若内部两留出几何有一致收益且幅度/动态无明显回退，再完整1367评估；无联合收益如实拒绝，不继续加参数/扫系数。开发probe本身有偏差，保留全部probe与GT。
5. 通过后按用户原要求输出八情感视频与原论文表格，保存来源、原生时钟和rig。此次不制作用户新提出的四种论文图片；需求在 PAPER_FIGURE_REQUIREMENTS.md。

远端存储仅约365MiB空闲。诊断只保存紧凑拟合记录/修正参数/内部报告，共预计60MiB以内；复用原数据和checkpoint，不删除历史证据。正式评估需要另做存储安排。诊断报告须先取回校验，才能决定新训练/候选采用。
