# 基座误差分解与下一版设计

本页回应 MBE/LBE 较高及音频时序路线问题。仅完成诊断和设计，没有启动新生成器训练。分析使用历史 64 条开发集的原始 target52、channel_mask、native valid 与冻结 baseline52。

## 新增实测诊断

- 每个有效帧都是 51 个可观测通道（tongue 缺失）。MBE=0.598774 是区域向量 L2；除以 sqrt(51) 得到平均逐帧通道 RMS=0.083845。LBE=0.329595 包含官方 12 通道，除以 sqrt(12) 得 0.095146。这是量纲解释，不替换官方主指标，也不是平均绝对误差。
- 在先按片段等权平均每通道平方误差、再求全通道占比的分解中，Upper9 占 20.84%，未更新其余通道占 79.16%。这是平方误差构成，不是 MBE 可加性分解。
- 最大误差源是 mouthPucker（全脸平方误差占 13.01%，MAE 0.16163）、mouthUpperUpRight（8.95%，MAE 0.13391）、mouthUpperUpLeft（7.62%，MAE 0.12247），随后为 mouthSmile 两侧。不能把当前系统的问题缩减为仅眉眼未完成。
- mouthPucker/upperUp 的逐片恒定偏置平方仅解释约 16%–19% 的各自平方误差；仅校准静态均值不足。部分眉毛通道约 79%–81% 则属于逐片偏置平方成分，提示应区分平均眉位置与动态。此分解使用参考目标，只作诊断，不能在测试推理做目标均值校准。
- 对官方 lip12 做固定共同内部帧的 -5..+5 帧位移诊断，0 帧的总体 MSE 最低（0.012294，+1 为 0.012432，-1 为 0.013055）。暂无“统一平移就能修好”的证据。此诊断没有改动已报告分数，不等于每条音频/视频的对齐都正确或 SyncNet 已通过。

## 两条分别验收的优化线

1. 基座口部：检查高误差通道的映射、原始拟合质量、时间对齐、动态幅度与共发音；在训练/验证划分内微调口部预测通路，先保持身份/全局情感与上脸先验冻结。不能简单增加整体幅度、平移测试轨迹或给每个测试片段拟合校准参数。以 LBE/Lip23、口部时序与校准后的 AV 评价共同判断；保留原基座同条件对照。
2. 音频眉眼：保留已改善运动分布的先验，引入显式随机事件日程，将事件发生时间/持续时间与具体动作形状分开学习。全局情感和身份继续作为条件。

拟议模型：`p(motion|audio,global,identity) = sum_event p(event|ordered_audio,global,identity) * p(motion|event,global,identity)`。事件为粗粒度抬眉/压眉/眯眼/睁眼的开始、持续、休止，不是 9 维目标轨迹。音频分支读取有序声学与韵律特征，预测发生概率和时长分布；时长建模避免逐帧独立开关。采样事件日程后，由条件 flow 生成动作形状与细节，保留随机性。

这不是首次加入时序网络：此前 flow 与 bounded adapter 已使用有序音频、膨胀时序块和随机 flow matching。新路线的差别必须是显式事件日程分解与可单独验证的控制机制，不能只是再拼一种条件特征。最近的窗口摘要+MLP 失败也只否定该候选，不能证明所有序列条件模型不可学习。

## 三个必须独立通过的验证

1. 从 fit 真实动作抽取粗事件；规则/阈值只在 fit 固定。先训练事件条件先验，固定随机种子做正常、平移、空事件控制。检查生成是否对事件时机和持续时间作相应响应。oracle 使用 GT，仅说明控制通路正常。
2. 单独训练音频事件模型，使用同容量静态对照，检查跨句事件概率 NLL/Brier、时长分布及正序/反序/错配。事件概率应胜静态；不能靠总预测 loss 或幅度证明成功。内部事件指标不替换文献主表。
3. 验证/推理仅使用音频预测或采样事件，检查标准 ARKit 主表、多样性、时序对照与口部效果。不得读取目标眉眼、目标均值或视觉教师特征。条件训练需要覆盖预测事件的不确定性；若引入预测条件训练，用 fit 内交叉预测避免用本片真实事件伪装音频预测。

目标是对音频事件有统计响应的合理随机运动，不承诺与唯一 GT 的每次抬眉逐帧重合。若音频事件模型仍不优于静态，应转查标注噪声、对齐和语义信息缺失，必要时增加文本/用户条件并对所有基线采用相同输入轨道，不能靠延长训练保证成功。
