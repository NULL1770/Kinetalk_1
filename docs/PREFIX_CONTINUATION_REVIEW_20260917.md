# 已知动作前缀续接：小集试验独立设计审查

2026-09-17。本文审查拟议机制，不表示训练已完成。只读既有代码与已完成history12结果；不改runner、数据成员或超参数，不读取开发/test目标。

**结论：值得先做有限接收器诊断，但不能称为已经解决chunk随机重采样，也不能将8条fit上的成功称为audio动态预测成功。** history12把8帧历史压成单向量后加入local，真实历史仍弱、部署眉边界位移约为参考10.77倍；新方案直接把已知运动帧放进同一轨迹attention，测试的问题更明确：模型是否能利用一个实际运动边界继续生成。

## 本次小集的确切范围

沿 `artifacts/history_context_20260917/tracking/selection.json`，固定 M003/M005 × neutral/angry/happy/sad，8条均 `L1_001`，均属于当前2315 fit。它们共享一句台词且均level 1，不是随机代表性样本，更不是新句或新身份测试。

每条沿现有96帧缓存分6个当前16帧窗口，配严格之前最多8帧历史，固定张量8+16=24帧；末窗/缺失帧保留mask。共48个窗口槽，batch8，每epoch6次更新，15epoch即**每臂90次optimizer更新**，并非只有15步，也不能写成完整2315条上的15epoch。若实现跳过空槽，以实际日志中的有效窗口、观测帧和更新数为准。

两臂都从history12/no_history的相同backbone/local初始化：`absent`无动作前缀、`teacher_prefix`提供真实过去8帧。冻结global、独立neutral身份及其余43通道路径，保持同音频、当前窗、噪声/flow time抽样和优化预算。这个诊断是在有训练历史的warmstart上做90步局部适配，并不是从随机初始化证明模型容量。

## 必须一致的生成契约

| 项目 | 本次应该固定的定义 | 不允许混用的情况 |
|---|---|---|
| 运动坐标 | `y=(upper-(独立neutral anchor+audio四状态整段均值lift))/fit_residual_RMS`，沿history12；不减GT均值 | 过去用raw系数、当前用normalized residual；各chunk重算不同坐标原点；额外乘旧renderer residual_scale |
| 已知前缀 | 仅当前窗之前、同clip的8个原生时间位置，保持间隙和有效mask | 当前/未来GT进入known token；把最后8个有效帧跨gap压成连续时间；跨clip接续 |
| flow路径 | 当前未知帧 `x_t=(1-t)noise+t*target`，FM仅监督这些有效未知帧 | 将已知前缀也计入loss，使“复制已知”降低平均loss；loss分母随已知长度变化 |
| clamp策略 | 推荐已知前缀作为恒定干净条件，训练所有t及每个solver步均保持同一值；不积分前缀速度 | 训练给带噪前缀、推理却clamp干净前缀；每solver步重新采样前缀噪声 |
| 噪声 | 每次生成每个未知时刻只采一次初始噪声，ODE各步固定；两臂未知帧噪声严格配对 | 为减接缝在无声明情况下固定GT相关噪声/选最好seed；跨步重采样 |
| mask/位置 | 独立区分known、unknown、padding；24帧位置固定0–23，未知总在8–23；无前缀仍用相同槽与位置 | absent改成16帧位置0–15，使比较同时改变位置；空prefix的embedding或attention无意泄露GT |

备选的noised-known路径并非不合法：若要用 `(1-t)*fixed_prefix_noise+t*known`，则训练和推理每个t都应使用这同一条已知路径，t=1回到known，并在报告中声明。它不应与干净条件clamp在两端混搭。本小集没有必要同时增加这个变量。

现有 `TemporalUpperFlow._LayerConditionedDiT` 已有固定native-frame sinusoidal位置，不是直接使用没有该位置项的基础ResidualDiT；只需确保拼接后前缀与当前窗位置约定一致。mask embedding不能替代时间位置，但也不需要因此再叠一个未验证的位置模块。音频/global仍可使用离线上下文，故本实验只能声称运动历史严格来自过去，不能自称整个模型在线因果。

## clamp保住过去，不自动保住新段均值

clamp保证已知8帧不会被solver改写；它**不会数学上保证第一个未知帧与最后一个已知帧连续**，也不会强制新16帧维持相同绝对均值。当前未知块仍从独立噪声开始，flow完全可能忽略prefix、重新选择一个偏置。即使首帧贴近，块内也可能漂移；所以“有prefix”不是已解决10.77倍接缝的证据。

当前audio均值基线在整段内固定，避免了GT均值泄漏，但预测误差仍可能由每块残差均值重新补偿。应直接比较每块raw均值、第一未知帧位移、边界与块内速度、最终连续曲线，而不是只报centered loss或把所有种子拉成静止。若有帮助，是新条件分布学会了续接，不是clamp天然施加了连续性约束。

## 训练过去与部署过去的差异

`teacher_prefix`拟合的是 `p(未来|真实过去,audio)`；实际从自己生成的过去续接，则面对幅度、偏置、噪声和越界都可能不同的prefix。首chunk没有真实历史，其错误会传入下一chunk。纯teacher前缀小集是合理的第一步，但不能跳过单独的**全程generated-prefix rollout**，也不能在每块重置成GT后把结果称为部署。

本轮无需同时启动新的scheduled-sampling训练来掩盖定位。如果真实prefix已有可靠收益、完全生成仍失败，结论应是接收能力获得证据但部署分布差异未解决；下一步才能独立评估生成历史训练/受控prefix扰动。若真实prefix仍弱，则先解决接收、参数化或优化，不扩大数据掩盖问题。

## 最低限度应报告什么

1. 保存初值和固定第15epoch结果，区分48窗FM训练loss与独立噪声完整solver生成。只降低带GT插值的FM loss，不算续接成功。
2. 同模型同seed比较：真实过去、空过去、反序过去、完全自己生成过去；真实前缀的已知8帧复制精度单独作为实现检查，不纳入未知帧质量分数。首chunk本无历史，真实与空前缀应一致。
3. 只统计有效相邻帧的边界位移RMS和位移误差，分别给参考值与块内值；同时给未知帧raw/centered误差、时序相关、动作幅度及越界率。单GT相关不是随机自然度的充分评价；8条数据也不足以做稳定分布/显著性结论。
4. 至少固定多个未用于选checkpoint的生成seed，保存连续raw曲线和视频；不得用smooth、gain、clamp后评分或best-of-K消掉接缝。显示clamp若必要，须与原值评分分开。
5. 验证其余43通道逐位一致、输入中没有当前/未来GT，以及teacher和absent未知区噪声、time、更新数可配对。冻结权重不能替代这些最终输出检查。

## 90步失败/成功分别能推出什么

**成功措辞**：在已曝光的8条固定fit数据上，90次更新后真实前缀可降低未知段接缝并改善续接；这为接收机制提供工程证据。它不证明新人物/新句泛化，也不证明audio含有相应细节，因为真实过去本身已携带强动作信息，小集可能被记忆。

**失败措辞**：当前warmstart、参数化和90步预算下未建立可靠续接；不能证明prefix flow无效或容量不足。若epoch0→15仍明显学习且梯度正常，唯一合理的后续是提前写明一个有上限的fit预算延长并报告全部端点；不得一边看结果一边无限延长直到“成功”。

若训练内都不学习，按顺序检查：未知loss/attention mask与梯度；训练/solver前缀值与归一化是否相同；已知保持测试；flow t分桶误差和完整rollout误差；当前token位置与absent对照一致性。若这些通过而真实prefix仍弱，可独立比较相同数据与相同坐标下的24帧连续重建能力，区分生成器拟合问题与条件使用问题。若只有少数噪声或极短期边界收益，不升级为正式大训练。

是否进入下一阶段，应基于**真实prefix接收 → 自生成prefix续接 → 当前fit以外开发验证**三项不同证据逐步判断；本文件不设来自已看开发数据的临时阈值，也不承诺90步足以决定成败。
