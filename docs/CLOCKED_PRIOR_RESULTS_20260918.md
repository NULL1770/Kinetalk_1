# 固定时钟运动先验：实测结果与未解决问题

三轮结构对照已经完成。**运动先验能够产生有幅度的眉眼变化，但音频对动作时机的可靠控制仍未通过；不能承诺继续优化必然成功。** 新版未替换默认模型，未启动无人值守的追加训练。

## 数据与评价范围

沿用1053拟合、199校准、353开发回归。199和353均已被多轮实验使用，上游冻结音频模型也有历史数据曝光；它们不是全链路未见测试集。所有结果都是开发证据，未读取封存测试。八个固定采样seed用于分布评分，不等于八个训练seed复现。句级bootstrap不消除反复设计和选择的偏差。

目标是九个眉眼系数：五个眉通道、四个眯眼/睁大通道。不含眨眼、视线或头动。Centered ES越低越好，评价生成分布而非强求单次采样逐帧复现唯一GT。幅度、速度、加速度、范围等工程门槛不是独立感知自然度验收。

固定时钟修复了此前音频32帧与动作16/32/48帧混用问题；单个训练片段均值的去除保留慢动作，没有逐窗口强制去均值。修正分支不使用GT动作历史或查询运动，静态音频抵消严格为零。查询GT只用于评分；字典、尺度、平衡姿态只由拟合单元学习。

## 失败定位与最新结果

高维修正在拟合前64个固定片段的精确窗口分布评分中改善0.13765，句级95%区间[0.09677,0.17705]；到199校准片段反而恶化0.01038，改善区间[-0.01769,-0.00117]。这发生在拼接之前，支持过拟合解释，而非只归因于渲染或拼接。诊断不训练、不选择新模型、不评分353。

低容量韵律修正只输入音高、能量、周期性、发声四通道，32帧分八格。静态基座、动作字典、归一化、平衡姿态全部复用。199上scale0/.25/.5/1分别得到0.650086/0.649749/0.648049/0.648472，按预设规则选择0.5。

353上相对静态的改善为0.002635，约0.48%，句级95%区间[-0.001013,0.007075]。倒序与错配对照的“对照ES减真实ES”分别为-0.000485和-0.000512，意味着倒序和错配略优于真实音频。因此未满足预先固定的至少1%提升、区间下界为正且胜过时序干预的判据，不能称“音频时序学出来了”。

最新四组幅度/GT约1.130、1.102、0.918、0.773；速度约1.038倍，353工程门槛通过。但199的睁大眼睛幅度约0.534倍，仍未通过，不能只报353的通过项。

## 下一步决策

不继续延长同一个完整轨迹分类器。下一项值得验证的结构是把“何时活跃、活跃多强”与“具体方向、形状和持续过程”分开：音频预测前者，运动先验采样后者；保留全局情感条件与身份执行基座。这是后续假设，尚未实现或验证，也不能直接声称方法创新。

先核对已有单field事件差分探针，避免重复失败路线。若进行新的验证，应固定四组活动概率目标、拟合阈值、低容量音频预测器、单一概率评分以及静态/倒序/错配对照。先证明这些较粗条件有跨句可预测性，再让它们控制先验的激活、保持和释放，并检查自由生成的连续性。未通过便停止这一接入，不以增加loss或轮次弥补。

若纯音频控制持续无效，可利用用户已接受的额外表达条件，如短参考动作的活动风格或可控表达意图；必须标清推理时额外输入，不能伪装成纯音频预测。参考条件也不能读取待生成片段的GT。最终候选仍需全链路未曝光句子/身份、独立口型和感知评估，才能讨论论文级效果。
