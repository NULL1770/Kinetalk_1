# 独立参考控制的稀疏动作先验：设计审查，尚未实现

执行更新：下文保留原proposal时间点。2026-09-18已实现事件生成器与教师审计；正式先验因监督不足未拟合。实际实现与偏差见[协议](SPARSE_BROW_EVENT_PROTOCOL_20260918.md)，结果见[实测](SPARSE_BROW_EVENT_RESULTS_20260918.md)。

**状态：proposal，未实现、未训练、未通过生成质量验证。** 本文建议先完成固定监督核验，再只做一个有退出条件的事件表示试验。它不恢复音频动作时机预测，不宣称找到动作语义或论文创新。本文不修改controlled_prior_v2及其负面结果。

## 现有证据与设计目标

当前连续Matérn先验已经证明状态可保持、释放和分块持续，但自然运动仍不足。已保存的四人×八seed、gain1的60秒样本，按既有速度范数>0.05定义的活动比例均为1.0。64个参考编码中30个tau落在0.08秒下界；1053个fit片段中28.3%触底，tau中位数约0.1033秒。这个统计不能区分跟踪微抖与真实快动作，不能直接拿来规定动作持续时间。32个固定开发样例上process的centered ES为0.560013，旧medoid为0.549784，退步1.86%；raw ES退步4.91%。因此下一版需要真正的静止间隔和有生命周期的变化，而不是把持续噪声再平滑或放大。

旧motion_process30的四组线段重构corr/R²较高，但约7个控制段/秒是重构压缩率，不是7个可感知动作/秒。它在教师当前状态和边界下学习持续时间及Gaussian位移；局部音频相对全局的留句NLL退步中91.8%来自位移项，留人95.5%。不能把这组结论解释成事件先验一定失败，也不能把类似线段再次命名为“起势/峰值”。新方案必须改变事件单位、稀疏状态和采样因果关系。

本次只推荐一个最小结构：**四组协调的稀疏半马尔可夫动作过程，由独立参考控制活动风格，由fit-only概率先验决定动作形态。** 每个事件是一次从保持状态出发、到新峰值再回落的完整变化；状态明确经过HOLD→ONSET→APEX→RELEASE→HOLD。HOLD期间没有逐帧随机运动创新。

## 先做可否决的动作教师，而不是先训练网络

四臂监督核验现已完成：28/32片触发至少一项重置敏感性阈值，主要在片头；平均活动标签分歧不足0.6%。32片隔离reset sidecar已生成，尚未纳入训练或经独立人工标注认证。需先修数据来源并核验可见动作；不能在不可靠系数上训练新事件先验并把平滑后标签当新真值。事件教师只能使用fit来源的原生有效run，不连接缺帧。

建议首版仅在**眉部两组**验证事件可辨识性，眼眯/眼睁保留旧基线或显式零动态；待眨眼、眼裂、头姿耦合核验后再启用。最终接口仍为九维，但不得将没验证的眼组和抬压眉一起宣称成功。四组同时提取统计可用于审查，不能掩盖组别不通过。

固定离线教师候选如下，需在运行前固化成单个协议，不能看到开发样例后搜索滤波参数：

1. 每个连续有效run内用5帧、二阶Savitzky–Golay平滑原始系数，首尾各2帧不产生事件边界。保留raw、smooth及差值；平滑仅用于教师提取，生成时不看query motion。
2. 用独立的“低运动可信帧”噪声估计：优先使用监督核验所确认的静止中性片段；没有这类支持时，使用fit高频残差MAD只能视为噪声代理并明确记录。每组阈值为固定绝对下限与该噪声代理倍数的较大者，所有阈值只由fit决定。
3. 以组内联合速度能量的双阈值进入/离开活动段，同时要求净位移显著高于噪声。至少连续3帧越过高阈值才起势；连续4帧低于低阈值才结束；不把单帧尖峰当动作。阈值规则必须逐组报告，不能用query自身RMS归一化。
4. 候选活动段内确定一个主要极值/平台，把上行、峰值停留、下行形成一个事件。双峰且中间没有可信HOLD的段落标记为“复合/当前表示不支持”，不强行分成多个短事件。起势或回落短于4帧的候选先记为不支持；在25Hz下这不是语义动作下限，而是本轮抗噪假设，必须报告被排除的帧/能量比例。
5. run边界、缺帧或片尾截断的事件保留左/右删失标记。HOLD的删失长度参与生存概率项，不能把片尾当自然结束；不完整动作不进入完整形状密度。

事件不是用动态规划最小化逐帧误差后任意选出的线段。一个事件的起势、峰值和回落合计计一次；另外单报每组和联合事件率、HOLD占比、复合段占比、raw/smooth峰值保留率。若结果仍达到约7次事件/秒，或者只有抹掉大部分可见动作才能得到稀疏事件，直接否决表示，不靠增大复杂度惩罚修饰报表。

固定核验：对已锁32段原视频按元数据选定的窗口覆盖静止、起势、峰值、回落，展示原像素与raw/smooth轨迹；标注起终点误差、动作是否存在、抬压方向和头动耦合。当前同一MediaPipe派生的landmark只能辅助定位，不能算独立真值。至少需要人工盲核一组固定片段；若没有，报告“教师可感知有效性未完成”，不声称语义动作。

## 具体学习什么

事件状态保存当前logit姿态x9、速度v9、加速度a9、当前阶段、阶段剩余帧数和已采样的事件参数。九维绝对情感level沿用冻结音频global65＋独立中性anchor的预测，事件模型只生成围绕level的动态；参考不提供level或query均值。

每个完整动作教师形成以下低维参数，而不是保存整段波形：

| 变量 | 定义及作用 | 训练数据来源 |
| --- | --- | --- |
| 等待时间d_hold | 从可信HOLD开始到下次动作；含删失记录 | fit事件间隔 |
| 联合组型m | 本次涉及哪几组及其有符号方向；先只验证眉组 | fit动作期间的显著净变化，不把噪声符号当标签 |
| 峰值向量p9 | 相对本事件起点的九维峰值偏移 | fit完整事件，按fit固定尺度表示 |
| 三阶段时长 | d_onset、d_apex、d_release；apex允许零帧 | fit完整事件边界 |
| 回落终态r9 | 回落后相对事件起点的偏移 | fit回落后稳定段；不是强制每次回中性 |
| 前序摘要h | 前一组型、结束姿态及静止龄期 | 训练用过去事件；部署用已生成状态 |

峰值、回落终态不应各通道独立拟合宽Gaussian，以免同时抬压眉、左右不协调或过度自信。最小模型采用**小混合分布的联合标记先验**：按fit联合事件参数拟合K=8个概率成分；离散组型和三阶段时长具有成分内概率，连续p/r使用收缩全协方差Student-t分布（自由度固定5）。K=8是首版固定容量，不根据已用开发集搜索K。如样本不足以支撑某组型，回退到已支持的较粗组型并报告覆盖，不训练空类别。

等待时长采用具有显式HOLD质量的离散生存表，而不是每帧加噪声。它由fit片均衡的等待时间及删失记录估计，使用预先固定的半秒年龄桶及小Dirichlet平滑；超过末桶继续用最后风险率，不把长片直接截短。初始状态默认从独立level的HOLD出发，避免再训练一个过度自信的初始Gaussian；另报从稳态事件相位初始化的对照，但首版不选其中表现好的版本。

训练目标是**一个联合事件负对数似然**，包含等待生存概率、组型/阶段时长概率与联合连续参数密度；每片总权重相同。不加轨迹幅度、速度或多项损失。可先用EM/最大似然完成，不需要音频编码器、扩散网络或GPU大模型；现有缓存和单卡预算足够。fit内部预先锁定按句开发折仅用于一次拟合诊断，不因结果更换头或重复训练。

## 独立参考如何控制，且不复制动作

query之外的同人、不同句fit参考，仅通过同一个事件教师压缩为五维：四组完整事件峰值的稳健幅度统计，以及可信HOLD占比；在首版眉部验证阶段只激活对应两组，其余维保留缺失/未验证标记。参考不足两个完整可靠事件的组使用fit总体统计，并明确报告回退。

与v2的RMS＋快速tau不同，这里的参考幅度描述**完整事件**，参考活动程度通过等待时间分布的固定条件插值实现。把fit片段按五维style归入固定的低/中/高三个活动层，学习对应事件分布；编码后的参考只选择/混合这三个层，不提供参考事件顺序、峰值方向或时间点。不同参考的平均姿态不搬到query。

显式用户控制分开定义：activity控制启动等待分布、amplitude控制已采样事件峰值与回落幅度。它们不是音频预测，不拿query GT校准。固定seed时，事件索引与独立随机子流决定组型、幅度、持续和等待；改activity不应额外消耗方向随机数，改amplitude不应改变动作起始次数。输出仍通过logit坐标的有界sigmoid解码，但越界为零不是质量证明。

每个阶段使用满足起终点位置/速度/加速度约束的五次曲线，将**采样的低维参数**解码为全新运动。这是固定可微动作解码器，不是参考波形拼接，也不是把连续噪声乘启发式包络。阶段时长、HOLD占比、峰值及回落终态均有fit教师监督。若解码曲线过于机械，表示检验必须显示失败，不能说“可控所以自然”。

## 保持、停止、释放与连续性

自动过程具有真正静止的HOLD。外部HOLD命令暂停新事件并以固定C2过渡结束当前速度；后续精确保持实际表情。RELEASE以固定C2过渡回到音频level，清空当前动作但不重置全局随机种子。恢复RUN从实际当前状态续接，不能突然跳到一个保存模板的首帧。

新事件在前一个事件结束前已采样完参数，renderer切块只改变输出批量，不触发重采样。测试覆盖任意切块、命令到达动作中途、参考交换和缺帧新run。参考交换只影响下一事件分布；正在执行的事件不立即改方向/幅度，以避免控制本身产生速度尖峰。事件索引、每一随机流及选中参数写入provenance。

## 唯一短验证及否决条件

先完成教师提取与固定片段人工核验；此阶段不过，不训练概率先验。以下工程判据需在实现协议中固化，不能本文之后根据结果宽松改写：

- 事件教师不跨gap，噪声尖峰不能在合成静止测试上触发；可见抬压眉在固定核验片段有明确对应。复合/删失/无支持部分逐组报告，不要求靠分段高R²掩盖其比例。
- 教师只覆盖足够真实动作时才继续；如近似每个细小波动都触发事件、HOLD几乎为零，或低事件率靠删除多数可见动作得到，否决。
- 在预先锁定的fit内部句子折上，完整事件联合分布与删失等待概率分别报告，不能用教师边界条件下的方向准确率称自由生成成功。
- 自由生成使用固定八seed和固定32个元数据query，不best-of。对静止占比、等待/起势/峰值/回落长度分布、事件率、组型共现、峰值/回落联合分布做后验预测检查；与原fit统计和已有v2统一口径。HOLD占比接近0或1均需否决相应style层。
- 低/高activity控制应改变事件次数而不强制改变单次形状；低/高amplitude控制应有单调幅度效应而不偷偷改变时机。参考交换只改变分布，不能出现整段参考近邻复现。
- 60秒延拓无漂移；任意分块逐位一致；HOLD末态速度为0，RELEASE到独立level误差<1e-6；同长度native窗口的速度/加速度和控制边界使用**同一预定fit基准**，不在fit中位数与95分位之间挑更宽的版本。
- 抬眉、压眉和未启用眼组分别看固定视频；43个非upper通道与无效帧逐位保持。全局表情、身份和口型仍需独立视觉验收。只有分布评分较好而肉眼机械、反复抖动或表情冲突，不能判自然度通过。

只允许这一次表示＋先验验证。若动作教师不可靠，回到监督修复；若教师可信而固定阶段解码器机械，明确下一缺口是动作形状表示，不继续换音频head或加训练轮数。本proposal没有结果，不能写成已实施的成功路线。
