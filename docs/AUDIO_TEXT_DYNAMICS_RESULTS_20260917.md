# Audio + 自动文本逐帧强度实验：完成结果与克隆核验

2026-09-17。结论：**两组短期训练已经完成，眉毛动幅增加，但尚未实现可靠的眉眼时序动态；嘴部输出保护未通过。当前不应替换默认模型，也不能据此认定满足论文发表要求。**

## 实际完成了什么

输入为 native 帧声学/韵律、自动 ASR 的冻结文本 token、原 audio-global；新增逐帧强度预测及 learned FiLM/fusion，训练新增编码器和整个既有 residual flow renderer。外部不要求情感标签。原 B0、身份模块、motion teacher、audio-global 全部冻结；继承历史蒸馏特征，**本轮没有继续在线 motion→audio 蒸馏**。逐帧强度是眉/表情眼相对独立中性参考的幅度代理，不是完整情绪状态。

text 与 matched no_text 两臂各 8 epoch、1,160 optimizer steps，2315 fit / 405 development，96 帧窗口，同初始化与随机流。主比较使用固定 8 个生成种子、句子级 bootstrap 2000 次；没有读取 sealed test，也没有按 dev 挑选 checkpoint。固定 fit 与 dev 共享句子，结果不是独立句子的最终泛化证明。完整协议见 [AUDIO_TEXT_DYNAMICS_PROTOCOL_20260917.md](AUDIO_TEXT_DYNAMICS_PROTOCOL_20260917.md)。

## 与历史完整模型的比较

下面采用历史 **full-local 完整模型** 作基线。新分支零初始化的 epoch0 等于旧 zero-local，不能将其写作旧完整模型。

| 指标 | 旧 full-local | 新 text | 判断 |
|---|---:|---:|---|
| 非中性眉动态 RMS / GT | 0.6452 | 1.0283 | 动幅增加、接近 GT 总量 |
| 非中性眉去均值轨迹相关 | 0.10618 | 0.10668 | 时序几乎没有改善 |
| 非中性眉动态 R² | −0.2793 | −0.8381 | 动态重建变差 |
| 非中性眉 raw 系数 MSE | 基准 | −8.62% | 包含均值的整体重建有收益 |
| 非中性眉去均值动态 MSE | 基准 | +43.68% | 幅度更大却没有对应准确时序 |
| 全体嘴部 raw 系数 MSE | 基准 | +11.86% | 输出保护未通过 |
| 中性 / 非中性嘴部 raw MSE | 基准 | +106.82% / +8.20% | 两组均恶化，中性尤其明显 |

非中性 331 条，中性 74 条。非中性眉 raw MSE 变化 95% CI 为 [−14.78%, −2.21%]；嘴部全体为 [+6.28%, +17.70%]，中性 [+90.21%, +123.30%]，非中性 [+2.72%, +13.99%]。嘴部指标涉及 27 个下颌/嘴系数，是数值重建误差，**不是唇音同步评分**。没有独立证据可保证本轮最终输出身份、口型和整体情感全部保持不变。

这里动态轨迹先减 B0＋身份基线，再按片段去均值；R² = 1 − SSE / GT 轨迹能量。负值表示按该指标甚至不如零动态残差。音频到表情是一对多，因此不只看与单条 GT 的逐帧吻合：主审计也检查了 8 种子公平 ES/VS。非中性眉相对共同 zero-local 初始化的这两项仍恶化，不能把动幅恢复认作分布建模成功；眼部不同分布指标结果混合。

## 文本与强度支路的实际收益

相对相同预算的 no_text，新 text 非中性眉 raw MSE 下降 2.25%（95% CI [−2.98%, −1.35%]），动态 R² 只提升 0.0074（95% CI [−0.0018, +0.0171]）。因此文本有小幅整体重建收益，**尚无可靠动态增益**；这不等于证明文本普遍无用。

文本与嘴部的归因补充：matched text 相对 no_text 的全体嘴部 raw MSE 下降 0.4268%（95% CI [−0.6375%, −0.1985%]），非中性下降 0.4604%，中性变化 +0.0307% 且 CI 跨零。因此不能把相对旧完整模型的嘴部退化归因于文本。两臂共同采用的条件结构、训练目标及整个 renderer 更新仍是待查因素。静态强度干预弱响应也意味着，动幅提升不能直接归因为显式逐帧强度控制奏效。

强度预测在固定 128 条 fit 上 raw Pearson 为 0.7477，但按片段去均值后仅 0.0620。全 405 条 dev 的强度动态相关为 0.0607，动态 MSE 0.01182，比每条使用自身预测均值的静态对照 0.00472 更差。当前主要学到片段间整体强弱，片段内的时间变化连训练内也没拟合好。

最终 text 模型的 seed42 干预中，改用 GT 强度仅使非中性眉动态 R² 改善约 0.005，眼约 0.0075。固定强度与正常预测的输出也十分接近；但固定强度时直接声学/文本隐特征仍随时间变化，因此这不是完全静态条件实验。

## 强度接收通路补充诊断

另外从 epoch000 开始，用固定 128 条 fit 做 oracle_frame / oracle_static 两臂，每臂 64 步。它是短期接收能力诊断，**不是与主实验 1,160 步等预算的对照，也不是模型能力上限**。

- 直接输入真实逐帧强度时，生成强度动态相关只有 0.01810；同模型改用片段平均 GT 强度后为 0.01548。
- 逐帧 GT 换为静态 GT，眉系数变化 RMS 只有 3.81e−5。
- 供给强度整体增加 0.25，生成强度均值只增加 1.35e−4，眉系数变化 RMS 为 7.66e−5。

这些结果支持：**在已测的结构与训练预算下，显式强度条件没有形成有效控制。** 不能由此断言唯一根因、证明这个结构永远学不会，或者把旁路压制/梯度尺度问题当作已定位的事实。分支数值尺度与梯度诊断尚未实施。

## 下一步的具体顺序

1. 先验证生成端：固定小训练集，用真实动态条件训练接收器，分开测试全局强弱、眉/眼区域活动量与有方向的局部动态状态。单个非负强度无法区分抬眉与压眉，也不能描述左右眉形态。接受标准要同时包括训练内动态拟合、条件打乱/置静态后的变化、控制幅度响应和合理系数范围。先证明接收器能用条件，再扩大音频预测训练。
2. 从输出结构上保护嘴部：保留旧模型的嘴/下颌输出，让新分支首先只修改眉和表情眼；检查相同输入和种子下未授权通道的输出差异。冻结 B0 本身不能保证嘴部不变，因为本轮整个 renderer 都在更新。
3. 接收器通过后再学习跨模态映射：区分片段均值与时间变化；分别测音频＋文本在 fit/dev 上的预测性。全局情感与 motion→audio 蒸馏可继续保留，但不能把全局目标当作逐帧监督的替代。窗口活动条件与前序动作上下文可以在此基础上逐项增加，前序上下文必须覆盖推理时使用自己生成动作的情形。
4. 对音频无法唯一确定的细节保留随机生成，使用固定多 seed 的动态分布和连续视频评价；不能靠每个 seed 都拟合唯一 GT 或单纯把方差放大来验收。

以上是基于失败诊断的后续方案，尚未开始新一轮训练，也不承诺单个部件补上后必然成功。
