# 收敛方案：音频逐帧表达强度与可学习条件生成

2026-09-17。用户要求具体设计及跨模态可学习性判断。本文件将前序候选收敛为一个主基线与后续增量；仅设计，没有新增训练。不声称已经找到唯一正确架构。

实施更新：后续用户已接受自动ASR文本。当前首轮实现以[AUDIO_TEXT_DYNAMICS_PROTOCOL_20260917.md](AUDIO_TEXT_DYNAMICS_PROTOCOL_20260917.md)为准：增加冻结文本token、直接用预测强度进行联合训练，不执行本稿候选B的cross-fit/GT混合；不能将下面的候选阶段写成已完成。

## 结论与固定主版本

主基线：保留B0、identity、motion-global→audio-global教师关系及单一52D残差flow；重新构建完整时钟声学和非中心化逐帧表达强度目标，通过可学习融合模块让预测强度参与生成训练。先检验这一完整路径，再在相同框架加入窗口眉眼活动量和前序生成历史。VA为另外的时变情感表示候选，本轮不同时加入VA和详细9D运动状态。

窗口activity与history仍是完整方案的一部分；阶段拆分只为区分表达程度、活动统计和跨窗连续性三种效果，不能将仅强度基线命名为SubtleTalk复现。

## 1. 实际网络与输入

```text
motion teacher global --训练监督--> audio global E_g --保留原入口--> DiT
完整音频 --> content ---------------------------------------> B0/h0
         --> 中间层声学 + emotion2vec + F0/voicing/log-energy
             --> 共享时序encoder --> softplus强度头 I_hat(t)
                                 --> 局部声学特征 z(t)
[E_g, I_hat(t), z(t)] --> 学习的融合 F --> 逐帧local condition --> DiT
identity + noise ----------------------------------------------> DiT
```

不用文本。首版复用已有内容和emotion2vec模型、真正完整帧特征，增加保留绝对韵律的统一时间轴缓存；不把“换WavLM”与条件路径同时当成单一归因。后续可在同协议替换多层WavLM作输入对照。

按训练集统计归一化声学，不逐clip去均值或做RMS归一化；保留停顿/voicing与无效帧mask，直接声学旁路不被单标量瓶颈替代。相对韵律可作为附加信息，但不能覆盖绝对能量/F0。绝对能量受录音增益影响，需分库归一审查及合理增益增强，不能把音量直接当情感真值。

旧E_g是无归一linear latent，同时承担类别/等级，范数没有明确定义为强度。故不直接使用I*E_g/||E_g||覆盖旧global。保留旧global AdaLN，新增`local=F(E_g,I,z)`；F可以用I生成FiLM参数调制一个学习的情感projection，再融合z。采用可恢复旧起点的输出初始化。若专门试MED单位方向形式，需训练新的emotion embedding/projection并记录norm约定。

初期global冻结，不能把没有梯度接收端的蒸馏项称为正在教学；联合微调audio-global时，使用固定坐标的motion teacher监督和标签语义约束。未来扩八类或新域先核验旧教师覆盖，不能默认旧权重无需重训。

## 2. 强度定义与边界

首版固定ARKit眉5通道与squint/wide4通道，排除gaze、blink、jaw/lip发音；不加入嘴角以避免旧happy ray嘴部主导问题。它是上脸表达幅度代理，非心理情感真值，也不是MEDTalk原14维索引的复现。

令m_j(t)为可靠观测、n_s,j为独立neutral参考的稳健中心、d_j为fit-only通道尺度并有下限：

```text
u_j(t) = (m_j(t) - n_s,j) / d_j
I*(t) = 0.5 * mean_brow(|u_j(t)|) + 0.5 * mean_squint_wide(|u_j(t)|)
```

该区域等权是本项目定义，避免5:4通道数隐式决定权重；缺失通道必须按观测合同处理，不能NaN变0。尺度以可靠fit幅度统计固定，不能用个人接近0的neutral std做除数，也不逐query去均值或除峰值。neutral仍可有自然变化，I不强制为0，移除对新动态条件的`1-p(neutral)`乘法开关。

绝对偏离也可能含放松、跟踪误差或neutral锚定误差；须在预选原片中核对。若平滑，滤波时窗预先固定并报告原始/滤后目标，不能调到音频最容易预测的版本再宣称还原原动作。GT时间戳先独立核验，不用开发集拟合最佳lag。

I只描述程度，不提供抬眉/压眉、左右或眉眼相对时序；方向由global语义、声学、identity和学习的decoder共同决定，最终逐通道监督负责约束。相同I可以对应多种合理动作，所以只让I匹配不能验收。blink仍参与完整motion生成和评价，只是不拿它替代情感强度目标。

## 3. 三段训练，两个相互独立的问题

**A. 接收端与跨模态预测端分别诊断。** 固定目标先进行小规模fit可达性检查。接收端使用I*与同一audio-global训练，比较constant/反转/正确I控制对最终生成的影响。预测端只用audio学I，按句/人协议评估。前者成功不证明后者能学，后者分数好也不证明动作改善。

**B. 预测条件参与生成训练。** 预训练I头后，在fit内按句cross-fit形成带实际泛化误差的预测条件，训练F和完整renderer接收真实I与预测I，逐步以预测I为主；配套端到端audio分支可将最终motion任务梯度传给I头，但保留固定I语义监督，避免标量变成任意隐藏编码。教师真值分支只作训练辅助和oracle，纯audio结果单独报。

**C. 在完整纯audio路径下验证。** 默认输出使用预测global、预测I、音频、独立neutral身份参考和noise，不使用GT类别、I或运动历史。验证同时检查表达幅度、方向/时序、多seed分布、实际rig显示和最终嘴部。flow任务、固定强度语义与最终输出保护分别负责生成、接口含义和可用性；不以latent拟合代替动作评价。

8epoch仅为匹配短对照，不能自动视为动作分布已学充分；先分清fit不达标、泛化失败与推理分布差异。历史global若见过内折句子，cross-fit只认证新强度头；不冒充整系统完全OOF。

## 4. 音频有没有信息：需要证明的增量

音频有语调、重音、音高、响度、语速、停顿、音质与内容线索，可以与表达程度/活动倾向相关；这些不是面部动作的完整观测。表演策略、语境、个体习惯、随机眨眼及tracker误差不由声音唯一决定。配对数据提供监督，不能凭空增加测试时音频的信息。

同固定目标、训练尺度和开发协议比较：

1. 训练均值/neutral参考常量。
2. 仅audio-global及整体统计的静态预测。
3. global加真正有时间顺序的声学预测。
4. 固定global，声学反转、平移，以及同类/尽可能同身份的错配控制；报告适用样本数，避免类别变了造成伪增益。

将整体水平误差与去时间均值的动态误差/相关分开；同时分眉/眼、逐人/类、按句置信区间。模型仅预测“angry平均更强”不能称时变强度学会了。时间干预只是诊断之一，必须与匹配训练和保留数据结果合用。

若动态误差不改善，但活动分布、适当评分和自然度更好，也可支持条件随机生成价值；不能要求一对多模型复刻全部GT眉峰。反过来，不把任何预测残差都命名为随机性：标签质量和欠拟合同样会造成残差。

本项目已有少量可预测成分：旧全脸scalar收益mouth主导，仅上脸ray收益很弱；中层声学+韵律在特定开发协议中有小幅眉收益。这支持继续检验，但不证明新I目标已可预测或一定足够。

## 5. 如何接回窗口activity和history

保持上述模块职责，新增A=(brow activity, eye activity)作为窗口调制条件，H为前窗已生成动作上下文。A与I联合预测或令A条件依赖audio/global/预测I/H，不能独立乱采样；I描述离neutral多远，A描述在窗内如何变化，两者有关但并非总能互相推导。眉方向反复变化也可能保持近似恒定I。

活动GT仅训练/oracle可用，推理采用音频条件分布或明确用户控制；训练需暴露于预测A。history由GT引导过渡至真实生成历史，首窗有空历史mask，不能用真实前窗作弊。活动模块主要检验幅度统计，history主要检验连续性；采用它们不等于证明两种能力已完成。

## 与历史实验的区别

旧upper_l1包含gaze/blink并去clip均值；旧run27–29将中心化标量映射为固定52D ray。新基线保留绝对表达程度、固定更明确的读出、使用可学习特征融合，并在预测条件下训练最终生成。排除gaze/blink本身以前也试过且未成功，因此不能将这一步单独当新突破。

这是可执行且可证伪的主基线。成功标准是纯audio最终动作的可见、合理、有条件关系的动态，绝不是“强度头存在”或“GT条件视频好看”。
