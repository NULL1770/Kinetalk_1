# 持续动作过程小验证结果

2026-09-18 已完成新模块实现、真实数据试跑及两组各30轮正式训练；全部基座保持原状。本轮把“动作表示能否承载变化”和“音频能否预测该表示”分开验收。第一关通过，第二关失败，因此没有接入全脸生成器或替换默认模型。

实现为四组异步持续控制状态：抬眉、压眉、眯眼和睁大，各自预测持续时间与带符号位移，跨块保留状态，允许保持、相反方向与重叠；训练动作采用可变时长线段压缩。它不是离散语义动作发现，不覆盖眨眼、视线和头部。现有全局情感、motion-to-audio全局指导及身份/口型模型不受本次独立试验更新；独立先验使用池化音频全局信息，没有重训这些基座。

在旧2315条fit中重新固定1605训练、275留句、375留人、60同时留出。新归一化和先验只用1605条；405开发集与封存test未索引。上游表示存在历史来源曝光，不声称全系统未见来源泛化。协议在正式训练前固定，失败后未放宽门槛。

逆序变差说明模型使用时序，但真实音频不优于静态/错配，不能把“使用时序”当成“正确预测动作”。训练损失local更低（3.296 vs 3.709），泛化似然却更差，需分解时长/位移及概率校准后判断原因，不能据此证明音频没有可学信息。

逐片RMS比对近静止GT敏感：例如留句压眉均值比118.54，而汇总能量的幅度比为1.51。原门槛结果保留，补充`rms_denominator_diagnostic.json`避免误读。两种口径下都不能掩盖时序、似然和越界失败。

本地71项相关测试通过；远端正式启动前55项、后续保存审计12项及诊断4项通过。保存结果审计重算6套全部8-seed曲线、训练顺序、2010步、归一化成员、两臂目标/掩码/参考一致性和两道门槛；审计通过。该保存审计与后文另行完成的神经前向似然复现是两项独立检查。

评审页面在`artifacts/motion_process_20260918/motion_process30/index.html`，含9条元数据固定样例、四组控制曲线及8样本范围。它们是独立先验曲线，不是完整面部动画。已有口型/身份/全局模型没被修改，本轮也没有重新证明这些部分的感知质量。

后续只读校准诊断与最终解释随同本轮结果保存；不追加相同30轮或强行接入失败先验。

只读前向诊断已完成：两臂三个留出集的逐片事件/初始NLL与原记录均零差复现。按原逐片等权口径，局部音频的留句退步2.2806 nats中，时长CE增加0.1877、位移Gaussian NLL增加2.0929（91.8%）；留人分别增加0.1067和2.2428（95.5%来自位移项）。按事件加权口径，local在fit的位移MSE/预测标准差/标准化平方误差E[z²]/2σ覆盖率为2.528/1.204/0.933/97.85%；留句为3.439/1.166/6.600/76.62%，留人为2.561/0.931/7.624/72.52%。这是拟合集表现较好、留出集明显过度自信的证据，且误差与预测方差的逐事件配合失效，不能仅看平均标准差判断校准。两臂初始状态也有明显泛化校准问题：local留句四组2σ覆盖率仅47.3%–67.6%，留人为32.0%–59.5%，初始状态不能视为已经解决。

下一步应把“校准能解释多少NLL退步”与“局部音频是否提供可泛化的动作增益”分开验证。单纯扩大预测方差不会修正位移均值或时长：local留句/留人位移MSE仍比global高6.2%/9.1%，时长CE亦更差，原自由生成时序指标也退化，因此目前只能说存在过拟合和校准失配，尚不能把问题归结为一个温度参数，也不能证明这种表示从音频不可学习。若继续，应从原1605条fit内部另划校准集，先测限制局部分支容量、向global先验收缩或限制局部方差修正的匹配对照，并单独处理初始状态；现有留出结果已被分析，不能再当全新确认集。约67%–73%的方向准确率来自带真实当前状态、前序位移和教师边界的似然评估，不能归因于音频独立预测方向的能力。任何新方案仍须通过未参与选择的自由生成检验后再接入生成器，本轮不追加训练。
