# 共享动态基量纲诊断：训练内三折

2026-09-16，执行前固定协议。生成端 loss 的训练 RMS 定标改善上脸但损害嘴部，未采用。本轮检验更早的瓶颈：用原动作量纲构造共享基，是否让嘴部的大能量挤占了可预测眉眼方向。它不是增加维数或区域分头。

## 固定内容

- 仅使用 `teacher_schedule_v1/data_locked` 的 19 人、2315 条训练数据。复用原来的三个句子折，逐折在其余句子拟合、在未参与拟合的句子预测；每条训练样本恰好获得一次 OOF 预测。405 内部跨身份开发目标、旧 280/439 开发以及封存 test512/15 均不参与本轮。
- 两臂共用 audio features、4 帧时钟、alpha=1、rank=8。alpha 沿用此前训练内 CV 选择，因此这次 OOF 是已有训练数据的诊断，不是独立最终测试或完全无选择偏差的估计。
- `native`：原单位真实中心化动作残差 Y 上拟合 RRR8。`scaled`：仅从当前折 fit 部分估计每通道 RMS，以正 RMS 中位数为统一下限，令 s=max(RMS,median)，在 Y/s 上拟合同样 RRR8。实现中把 1/s² 的通道均值归一到 1；这是对所有输出同乘常数，线性拟合和逆变换后预测等价。每折输入 RMS、目标 RMS、基和线性系数都重新拟合。不按区域手调系数。
- 预测必须还原原动作单位后比较。缩放空间基 U 的音频预测为 `(X_std B) Uᵀ diag(s)`；真实动作教师为 `(Y diag(1/s) U) Uᵀ diag(s)`。后者是缩放度量下投影，不能把 U 当成原单位正交基；其原单位 R²可以为负。

## 评估与判定

不训练 renderer，不加生成头、loss 或推理输入。沿用原基诊断，不施加 audio gate。比较音频预测与 zero/时间反转，同时报告 motion 投影 oracle；所有误差用真实原单位目标、实际有效帧权重。报告 nonneutral/neutral/all、眉/眼/嘴/上脸、逐人、相关与 RMS、按句配对 bootstrap 5000 次。区域只用于诊断。不能把 oracle 的提高当音频动态已学会，也不能只凭幅度变大判断成功。

先检查每折没有句子泄漏、OOF 覆盖完整、heldout poison 不影响拟合、inverse scaling 与缺失/填充掩码正确，再运行真实数据。保存输入/源码 hash、每折 state、OOF 预测和统计。若音频眉毛没有可信收益或嘴部明显恶化，则不接入生成器；即使通过，也必须另做最多 8 epoch 的生成对照，才能判断最终动态和防退化。

本轮不改默认权重、不删除数据，不承诺发表或动态必然成功。

## 实测结果：不采用 scaled

两个 arm × 三折全部完成，2315 条 OOF 覆盖完整、67 个句子、19 人。nonneutral 为 1893 条/52 句，neutral 为 422 条/27 句。native 每折精确复现原锁定分数；独立审计从原曲线重算全部充分统计、pooled bootstrap，检查句隔离及 oracle 双基坐标还原，全部通过。

|nonneutral 音频原单位 R²|native|scaled|scaled−native 的95%句簇CI|
|---|---:|---:|---|
|上脸|.020713|.020997|[−.000694,+.001263]|
|眉|.020650|.020042|[−.001984,+.000739]|
|眼|.020822|.022671|[+.000250,+.003548]|
|嘴|.088888|.087631|[−.002300,−.000164]|
|jaw|.041073|.036782|[−.006384,−.002377]|

基定标确实改变了表达容量：真实动作眉毛投影 oracle R² **.36303→.55654**，19 人全部改善；但音频眉毛只有 6/19 人改善、13/19 人变差。native/scaled 两臂眉毛都弱于零基线的身份是 M012、M029、M031、M040、W036。scaled 眉预测 RMS 比 .13794→.15034，却伴随相关 **.14382→.14182**。音频顺序有用（native/scaled 眉 full−reverse +.04566/+.04993，CI 正），但目前弱信号并未因多保留眉毛方向而变强。该结果不支持直接加 rank 或把新基接进 renderer。

不是简单缺幅度：对固定预测曲线，设 RMS 比 a、相关 ρ，任意统一增益 g 的 R² 为 `2gρa−g²a²`，最多为 `ρ²`。当前 native 眉上限约 .020685，几乎等于实测 .020650；scaled 上限 .020114，也接近实测 .020042。这里只是现有固定曲线的代数诊断，**不是音频能力/架构上界**，没有把评估集最优 gain 用回模型。要提高的是时序相关性。

neutral 嘴 R² −.29757→−.28070，虽改善仍明显不如 zero。这是无 gate 的直接残差预测诊断，不是最终生成口型评分；不能据此撤掉既有 neutral gate。单一新基既没有眉收益又有嘴/jaw代价，故不进行后续生成训练、不替换默认。

全量270测试通过（81条既有Transformer警告），新增6项覆盖泄漏、坐标、掩码和原结果复现。输出及完整曲线在远端 `teacher_schedule_v1/scaled_basis_oof_v1`；本地保存权重、报告、源码快照、图和哈希备份。输入文件包含405的容器metadata并被整体字节hash，但只索引训练tensor；没有访问405目标值或最终测试。

下一优先级：固定 native rank8 目标、特征与三句折，单独对照**音频时序预测映射**，而非继续改变生成loss或放大控制量。当前线性头逐bin映射已有上下文音频特征；可检验一个共享轻量时序修正，保持单一目标和最多8epoch。旧224条上TCN试验失败，不能因换大数据便预先认为会成功；新的对照须把基/尺度/预算固定，先获得眉相关及zero/reverse收益、嘴部不退步，再接生成器。这个新预测器尚未实现或训练。
