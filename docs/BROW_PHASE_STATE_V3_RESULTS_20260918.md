# 删失状态监督 v3：修正、核验与未通过结论

本轮完成第三版监督代码、32片实测、眉眼共现诊断及原像素对照。**自然动态仍未训练成功，也未启动新的音频训练。** 默认生成权重、原数据、训练清单均未改动；没有读取405开发集或封存test。

## 撤销初稿结果

本轮初稿曾输出“85.1%可用覆盖率”。独立审查发现：将缺静止支撑误当边界删失、混合抬压眉组、候选先后次序决定标签、原地清除unsupported、半开run边界多收一帧、未知补集直接当HOLD。该数值**无效，不能用于论文、训练或效果比较**。旧远端目录已写入`INVALIDATED.txt`；保留作失败记录。

当前源码 schema 为 `brow_observed_state_v3_r3`。初稿的18项测试不足以验证这些语义契约，不能以测试通过替代监督正确性。

## 实际实现

按抬眉组 `[43,44,45]`、压眉组 `[41,42]` 分别标注，保留组内方向。输入只使用上一轮经过hash锁定的32片fit审计原始副本，SG5/2与0.035幅度下限不变；本轮不是独立未见测试。

- **STATIC**：局部稳定且整段变化不超过阈值的一半。持续高眉形可以是STATIC，不能据此称动态ACTIVE。
- **TRANSITION**：净位移超过阈值、至少4帧转移、净位移/总变化≥0.8；知道变化方向，不必知道是起势还是另一方向动作的回落。
- **ONSET / ACTIVE / RELEASE / HOLD**：只在相邻相反方向变化及中间平台，或有支撑的单峰/谷形状，能够识别动作阶段时标注。ACTIVE允许只有一个顶点帧。
- **UNKNOWN / UNSUPPORTED**：无效帧、首尾SG保护、无足够证据、冲突区域，不参与阶段监督。连续多峰可能有峰/谷两种分解，冲突不能解释成原始数据没有动作。

真正触及观测边界的变化记录左/右删失；片端、无效帧间隙与SG保护类型分别保存。未观察到起点或终点的持续时间是下界，不能当作完整时长。单调斜坡不能仅凭方向强行选择ONSET/RELEASE。`known_mask`仅表示机械状态证据；阶段训练须使用独立的`phase_known`，两者都不是语义认证。

## 固定32片结果

32片3505帧，每组3377个有效内帧。下列“覆盖”分母是每组3377帧，不混合两个组，也不把STATIC算作已知事件阶段。

| 量 | 抬眉 | 压眉 |
|---|---:|---:|
| 机械状态已知（含STATIC和TRANSITION） | 50.99% | 47.29% |
| 动作阶段可识别（含有事件依据的HOLD） | 6.84% | 3.94% |
| 事件候选 | 9 | 5 |
| 完整且无冲突的组事件 | 5 | 4 |
| 边界删失候选 | 1 | 1 |
| 已知阶段覆盖的组内差分能量 | 27.92% | 7.28% |

14个是**组事件**，存在跨组同时发生，不能称14个独立联合动作。9个完整无冲突组事件也未做感知认证。v2的20个候选与本版定义不同，数量变化不是质量改善。

有边界条件的五次曲线重构RMSE为抬眉0.01387、压眉0.01176，仅在机械已知区域计分，且使用真实端点与边界；不能当成音频预测或自由生成表现。数组中未知区域保留NaN，不插值掩盖缺失。

## 眨眼、眼裂与头姿

独立诊断脚本对32片fresh-forward数组进行原生同钟差分，不跨无效run或时钟间隙。眨眼值>0.5的±2帧邻域覆盖3473个有效差分中的222个（6.39%），承载抬眉19.67%、压眉16.46%的组内通道差分平方能量。

眼裂与头姿也逐片输出差分相关和可观测率，常量相关记null。**这些量来自同一MediaPipe跟踪器，只能说明共现，不能证明伪动作、独立真值或因果关系。** 不因上述相关直接删标签。原像素窗口全部按既有RGB SHA核验，14个组窗口纳入对照页；当前目视不是独立盲评。

## 像素运动核验（已完成）

32片3505帧逐帧RGB SHA全部匹配原审计。每个有效run只用首帧landmark定义眉区和稳定区域，后续用像素LK跟踪，并扣除稳定区拟合的二维相似变换，不逐帧重新锚定、不补特征点。双眉各3365/3473个相邻帧可观测（96.89%）；缺失108对全部来自`mead_M003_happy_L3_028`的后段，该片仅前21/129对可测，其余31片全部可测。缺失为NaN，不能当静止。

同支持帧去二维刚性后的右/左垂直运动能量分别剩原始的17.17%/15.19%。这不是“只有这些比例是真动作”的分解：三维头姿、皮肤、光照和LK漂移仍会影响残差。初始区域也依赖同一tracker，因此只称半独立像素证据。

不搜索时延，抬眉对照`−dy`、压眉对照`+dy`；平滑系数差分与双眉平均残差的相关如下：

| 区域 | 抬眉 | 压眉 |
|---|---:|---:|
| 全部共同可测对 | 0.301 | 0.171 |
| 眨眼邻域 | 0.163 | 0.133 |
| 非眨眼共同支持 | 0.335 | 0.178 |

非眨眼逐片分别25/32、24/32正向，但整片正相关不能批准片内每个事件阶段。没有据此删标签、拟合新阈值或训练模型。16项像素测试含7项独立旋转缩放/局部眉动/遮挡测试通过；关联分析另6项契约测试通过。

## 下一步与训练决定

严格状态教师仍漏掉大部分动态阶段，暂不适合训练完整四阶段及等待分布；不能用更多epoch修正标签不确定性。该结论不禁止所有连续运动先验训练，不能把不满足完整峰谷定义的轨迹当静止。状态/像素代码降为监督诊断工具，不作为下一主模型的必需情感条件。

如果真实动态是持续、重叠、无清晰静止边界的形态，下一模型应保留有方向的局部运动表示，而不是强迫所有片段符合完整四阶段事件。优先补监督与验证自然运动形状；只有动作重构可靠后再评估音频条件相对于静态条件/打乱音频的留句增益。全局情感与身份基座保留；它们及口型的独立感知质量仍需验收。
