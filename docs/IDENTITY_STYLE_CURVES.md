# 身份 / 风格曲线的证据与使用方式

输出位于 `final_experiment/evaluation/paper_reference_20261009/figures/`。

- `05_identity_style_curves`：同人 A/B 与跨人交换差异，以及交换前后到目标说话人动作统计的误差。目标点按配对数量加权，类别之间不画成连续轨迹。
- `05b_style_native_<emotion>`：八个既定视频片段各一张逐帧图，PNG/PDF/SVG/CSV。上排固定音频、B0、全局情感和局部条件，只换 M025/M037/M039 的参考；下排比较同人的两条独立 neutral 参考。四列为张口、笑容均值、内眉上提和左右笑容差。

全部来自 Phase53 style-only 的已核验原始输出，没有平滑、重定时或重新选择最佳片段。主图使用生成系数 clip[0,1]，GT 保留原值；原始动作文件及 SHA 绑定在绘图 JSON 中。Source GT 只是源说话人的表演背景，不能当成切换到另一人后的逐帧真值。

同人参考嘴部 MAE 0.005627，跨人 0.026865；同人/跨人约20.95%。这支持参考作用及部分稳定性，不等于证明身份识别、几何身份或完整内容解耦。原审计还显示跨人闭口差异约32.45%，需要保留这一限制。三位开发身份不足以证明普遍泛化，八情感曲线均提供以避免只展示 happy。

当前 Phase60 的新参考干预存在 B0 对照不一致，不能用于本图或身份结论。本图只引用原 Phase53 的单因素审计。
