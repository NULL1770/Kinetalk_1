# Persistent motion-process pilot — 2026-09-18

This is a new-module feasibility experiment, not a claimed successful generator or novel paper method. The previous native-context experiment improved continuity but did not recover reliable upper-face timing. No historical model/default is replaced by this pilot.

## Fixed scope and data

Use only the 2,315 historical fitting queries and their verified full-native audio/motion. Load the existing archive with mmap, index only its train role; do not index the 405 development or sealed test role. Sort speaker and sentence identifiers by SHA256 of `motion_process_20260918:<kind>:<id>`; hold out the first four speakers and first thirteen sentences. This makes four disjoint cells: fit, sentence, speaker, joint. Fit all new normalization, motion scales, teacher segmentation and prior parameters using the fit cell only. Applying the fixed teacher segmentation algorithm to holdout motion is evaluation-target construction, not a deployment condition. Frozen upstream representations have historical source exposure; this is not whole-system unseen-source generalization.

## Representation

Read four raw channel groups: brow-up (43,44,45), brow-down (41,42), eye-squint (5,12), eye-wide (6,13). These do not cover blink, gaze or head motion. Use fit-only group dynamic RMS (floor .005); independent neutral enrollment anchors define state origin, never query mean. Per group, dynamic programming fits endpoint-connected linear segments with durations 4,8,12,20,32,48,64 native frame transitions (25 Hz), plus a shorter terminal segment. Objective is integrated squared reconstruction error in fit-scale units plus fixed 1.0 per segment. Groups overlap asynchronously. Signed delta zero allows hold; a later opposite delta allows return without requiring return to neutral. Decoder retains current/start/end/age/duration across arbitrary inference chunk boundaries. Gap runs are separate; no compression of the native clock.

Continuous scalar delta per group is a compact geometric motion teacher, not a semantic/discrete discovery claim. It retains target information and needs separate cross-modal validation. Report segment rate and scalar payload rate rather than inventing a compressed bit rate for real-valued parameters. Compare an oracle constant per-run mean and uniform linear segments at the same segment count. Terminal segments are right-censored and excluded from joint completed-duration/delta likelihood targets; this is a conditional-on-completed-segment diagnostic, not a full survival likelihood. Do not interpret censoring as a true action ending.

Before prior fitting, all three holdout cells must have pooled per-group centered R2 >= .50, correlation >= .80, RMS ratio in [.75,1.25], and total segment rate <= 12/second. Report channel-level information loss separately. These are engineering gates fixed before results, not publication standards. Failing this gate stops generator integration.

## Prior and fixed comparisons

Train two identical small models from matched initialization/order, seed 20260918, 30 epochs, AdamW lr .0003, batch 24, weight decay .01, gradient norm 1. Train local+global audio versus global-only audio (time-mean input), using only train-fit native features normalized with new fit-only statistics. Existing global emotion/identity/mouth models are unchanged. A future integration may retain the existing global-emotion embedding; this stand-alone test uses pooled acoustic information so the new-module split is explicit.

Initial four-state Gaussian uses pooled audio. At action boundaries the network predicts categorical duration and duration-conditional Gaussian delta, conditioned on local audio, pooled audio, group, current generated state and previous action. During training, teacher boundaries/state are used for proper likelihood; evaluation deployment uses sampled initial state and generated boundaries/history only. No motion or event boundary enters acoustic encoding. Dropout is absent to keep paired initialization/order exact.

Final epoch only; no holdout checkpoint selection. Report per-clip joint completed-event NLL, initial NLL and duration Brier. Evaluate 8 fixed draws (42,123,2026,77,91,301,509,997) with full free rollout. Report raw/centered fair energy score, variogram errors at lags 1,4,16,32, mean errors, correlation and generated/reference RMS, out-of-domain fraction, per-group and per-speaker/emotion. No best-of-N. Teacher likelihood and free-run metrics have distinct scopes.

Real local audio also gets static-local, reverse-local and same-speaker/emotion different-sentence mismatched local interventions with pooled audio held fixed; intervention support is explicit and excludes unmatched clips. These diagnose use; paired global-only training is the main incremental control.

Audio gate: on sentence holdout, completed-event NLL improves by >= .01 nats/event with the 95% sentence-cluster bootstrap CI of the paired gain above zero; speaker holdout gain must be positive. On sentence and speaker holdouts, every group's centered/raw fair ES and variogram score must not worsen by >5% versus global-only (positive control denominator floored at 1e-12). Every local model group must also have mean per-clip generated RMS/reference in [.25,2] and raw out-of-domain fraction <=5%. Missing/nonfinite metrics fail. Joint cell is fully reported. Only if both representation and audio gates pass, integrate a predicted/sampled plan into the generator, run a matched no-plan comparison and separately verify 43-channel/invalid preservation, upper-face quality and global emotion. A failed audio gate warrants diagnosis, not a blind longer generator run.

Implementation clarification before formal fitting: both arms' pooled input is the same shared-parameter `encode(mean_audio)` path. Local arm additionally encodes the temporal sequence. All dynamic centering uses each contiguous valid run, not gaps treated as movement. Mismatch donors are same-cell/speaker/emotion, different sentence; donor local encoding is linearly resampled separately to each target valid run while target pooled context stays fixed. Compare interventions on their explicit common support. Random streams are keyed by seed/clip/group/event index, independent of batch composition and chosen durations. Initial-segment and interior-event likelihoods are reported separately. These control segments remain on a four-frame boundary grid, not discovered semantic events.
