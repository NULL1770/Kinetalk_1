# 连续动作表示与音频条件生成：具体修改方案

2026-09-19。用户认可新路线并授权实现及自动训练。模型、数据入口、评价、可恢复四阶段runner和后台supervisor现已实现，远端81项测试通过；正在做真实数据GPU短流程测试，正式运行状态见`CONTINUOUS_MOTION_LATENT_RUN_20260919.md`。阶段验收用于定位失败，不以实现新模块代替研究效果。

## 范围与保留项

首版生成抬眉、压眉、眯眼、睁眼共upper9，不包含blink、gaze或head。保留B0、身份、全局情感权重及历史motion-global到audio-global关系；冻结不等于在线继续蒸馏。非upper43及音频无效帧逐值复制原基座。upper变化仍可能改变身份/情感感知，必须看全脸视频。

一条主路线：连续动作AE → 冻结decoder后的latent联合先验 → 直接音频条件。VA留作历史对照，不进入新主线。已有未集成audio_event_condition.py不纳入首版，不强制以声学阈值触发抬眉。

## 已核接口与数据修改

1. baseline exporter保存了channel_mask，visual semantic dataset builder却没有传入。新入口恢复动作观测mask，不用VA的semantic_valid代替动作质量。
2. 当前runner只输入affect_global，另存的affect_intensity没有拼接。新接口显式拼接并核验实际维数；identity同样从缓存核验，不能按类默认值猜。
3. 当前SemanticUpperFlow的训练坐标是绝对motion的logit减fit统计均值，不是相对音频基座残差。新raw残差是待验证改变，不说已证明旧坐标造成失败。

```text
audio          [B,T,1540]  原生25Hz音频/韵律
motion9        [B,T,9]     仅训练/评价
baseline52     [B,T,52]    冻结音频推理，不读query motion
global         [B,Dg]     concat(affect_global, affect_intensity)
identity       [B,Di]     独立中性参考
native_valid   [B,T]      生成支持
motion_mask    [B,T,9]    监督支持，不控制部署时长或随机数
```

原192/64缓存已扩展为819训练/64诊断，共883段。扩展严格排除预先声明的8个留句（原64段只覆盖其中一部分），新增627段均为train。实际train联合观测0.97291小时；global65、identity128、context202。使用固定预算终点，不按64诊断集选择epoch；自动继续门控只看元数据预定的16条train。只用历史fit，405和封存test不读；上游见过来源，仍是内部开发。

训练时联合编码使用九维完整观测的连续段，不跨gap、不填零造latent真值，排除量公开。训练观测支持与推理音频支持分开；推理只用native_valid。无需等人工四阶段事件标签才能开工，现有原视频抽查与目标rig显示共同核验。

## 一：连续时序AE

```text
b9 = 冻结音频基座upper9在音频有效帧上的均值
r  = (motion9 - b9) / fit_only_scale9
z  = encoder(r)
reconstruction9 = b9 + fit_only_scale9 * decoder(z)
```

不读取query目标均值；b9是非因果整段音频条件，不称实时流式。r仍可能含基础表情误差，不假定天然纯动态，最终均值与片内变化分开报告。

首版每5帧按顺序打包45维→时序编码→16维latent，产生5Hz隐序列。**打包不是均值池化**；decoder输出每token的5×9帧，恢复25Hz，避免先平均掉眉峰或只做低频线性插值。初始hidden64、四层膨胀1/2/4/8提供约6.2秒latent上下文；块内相位、块间接续、尾mask和gap均需验证。5Hz/16维是实现起点，不保证保真。

AE先用训练尺度归一后的观测重构目标，不叠加VA/事件等监督。检查目标→重构→实际rig的完整路径，包括方向、峰谷、停留、幅度、速度、频谱。与同时间压缩率的简单插值对照比较。若训练内确认瓶颈抹峰，允许一次明确的容量修正；不看64留句反复搜参数。

首版raw线性解码可避免固定logit偏移在近边界缩幅，但可能越界。保存raw和显示后的曲线，报告裁剪比例与幅度损失；不能靠隐藏clip让结果过关。raw优于logit尚待实验。

## 二：latent连续运动先验

冻结AE，在真实编码的latent上训练conditional flow，条件为global、identity、b9。随机变量在latent时钟采样，时序网络联合生成整个有效段，decoder恢复原生动作。5Hz噪声不是自然度保证。

初版全段联合生成，不独立采样小窗再拼接、不输入GT历史。训练随机裁剪不跨缺口，整段和更长生成检查上下文局限及漂移。global-only仍含来自音频的全局信息，准确称“无局部音频先验”。

AE的确定性重构可以用单GT误差；生成先验用flow matching学习分布，不把每个随机输出都强拉向同一条GT。FM也可能失败，需自由生成验收；fair ES是分布评分，不等于点回归MSE。

## 三：直接音频条件

现1540维音频先投影，保留窗口内顺序后对齐latent钟，直接调制流场，不先预测VA或唯一九维动作。条件学习活动偏好、节奏和动作组合概率，不规定重音必抬眉。

从验收后的global prior分叉audio/global-only两臂，复制同一起点、相同容量接口和额外训练预算；global-only屏蔽局部信息。decoder冻结，流场允许适配，配对样本顺序、noise/time。不是再次仅训练极窄接口并冻结整个接收器。

另做同audio模型static/reverse/同情感异句错配，固定global/id/b9。干预可能分布外，故必须有匹配训练global-only主对照。音频只胜反序却不胜global-only，不称有实用收益；音频训练破坏自然度也不通过。

## 固定交付与定位

| 阶段 | 交付 | 核心问题 | 失败时处理 |
| --- | --- | --- | --- |
| AE | 原片/目标rig/重构同钟全长视频和原单位曲线 | 可见完整动作是否被保留 | 目标差查监督/显示；目标好重构差查容量；先不训音频 |
| 先验 | 多seed自由生成、旧300轮基线、长生成 | 无目标运动时能否自然起落/停顿 | 查latent分布或先验；短好长坏查上下文 |
| 音频 | audio/global-only及时间干预，同步全脸 | 是否在自然度基础上增加语音适配收益 | 查跨模态学习，不盲目重做动作表示 |

沿用四个情感旧样例，再按元数据补足不同身份，输出前锁定；旧四例全M003不能代表全体。完整片长，四seed42/123/2026/77，无best-of。目标upper9+基座43必须标“合成参考”，长自由生成只验证连续性，不冒充长GT匹配。

动作自然性和语音适配分报：分布评分、幅度/速度/频谱、均值漂移、固定多seed视频共同判断。单GT逐帧相关不能独自否定合理随机动作，随机性也不能解释无关抖动。不凭空设通用自然度阈值，用fit原动作及旧失败结果建立参照，边界结论记证据不足。43保护不等于整体感知已合格。

## 预算与边界

预算为AE4000、prior8000、matched_global6000、audio6000，共24000次更新，batch24；启动前真实GPU各100步短流程测时。每阶段保留last和固定终点final，last每250步更新；64留句只作阶段终点诊断。AE检查重构能否胜过同片常量，prior检查有限值/43保护/严重坍缩、越界或过快运动；这些宽松工程门控不认证自然度，失败停止后续长训。末期两适配支的门控只记录以完成公平对照。每阶段一个主候选，仍失败明确数据/表示/先验/映射哪层受阻。

上述四个模块及launcher、selection合并器已实现。81项测试覆盖pack/unpack、缺帧、fit-only统计、目标污染不影响推理、43保护、配对噪声、断点逐值恢复及四阶段CPU小流程。评价自动保存完整原生曲线、52维NPZ、SVG/HTML和渲染任务；服务器流程暂不自动渲染MP4。已加入real/static/reverse/同情感异句mismatch，后者只在同split选音频供体，保留query全局条件、身份、b9和随机数；时间缩放可能产生分布偏移，matched_global是主对照。

长于训练200帧的自然有效段按完整长度评价；专门长合成序列压力测试、真实rig视频复核及5帧插值重构对照仍待结果复核时补齐，不把自动完成等同这些检验已完成。正式运行后不修改已绑定源码；恢复校验数据/代码/统计/AE权重和预算哈希。断电后需显式resume；SSH断开不影响后台监督进程。
