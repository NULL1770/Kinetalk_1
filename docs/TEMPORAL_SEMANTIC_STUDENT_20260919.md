# 局部语义时序学生：实现与判别协议

2026-09-19。接续视觉语义六臂300轮实验，用户授权继续优化。目标是改善音频条件的时间信息，不承诺一次成功。使用原192训练/64留句内部开发数据，沿用原三句OOF；不读取405或封存test，不用holdout选epoch或幅度。

## 第一代局部残差学生

每个OOF fold精确绑定原ridge静态头与PCA，冻结整段音频到静态语义的估计。5Hz窗口PCA64原值与去片均值变化拼接，hidden64四层膨胀TCN(1/2/4/8)，局部感受野31窗约6.2秒；输入/输出音频片均值使整体为非因果整段模型。训练目标为窗口VA2与log(mean posterior8)减各片已观测教师均值，fit-only目标RMS缩放下限0.05，单一残差MSE，clip等权、窗内按教师有效帧数加权。

推理只读音频features/native valid、冻结模型。预测残差按全部音频窗帧数去均值，再加静态raw语义；VA截[-1,1]、类别softmax。不将raw均值守恒误称最终语义均值守恒，报告同时记录全音频支持及视觉评分支持的均值漂移。视觉检测缺测不控制推理。

固定120epoch、AdamW3e-4、weight_decay0.01、gradclip1、batch16、seed20260919。全192模型1440更新；OOF按实际拟合量1200/960/960更新，四模型训练和预测47.66秒。不是完整系统长训。源码`fit_temporal_semantic_student.py`，保存全部模型、成员、PCA、loss历史、代码/数据hash。19项实现与独立测试通过。

实际第一代学生未通过：64留句VA centered MSE为0.027253，静态0.016630，旧ridge时变0.019214；软概率centered Brier为0.083611，静态0.056975，旧时变0.071812。训练池OOF同样退步。新学生正常顺序优于逆序，但尚未胜静态，不能称学成。常量声学同网络的VA centered0.020610、软概率0.064682，仍产生无声学变化支撑的时间模式。

## 同一冻结接收器诊断

`evaluate_semantic_student_transfer.py`固定原VA/audio与posterior/audio的300轮接收器、归一化、25Hz mask和四采样seed。分别输入旧学生、新学生、旧静态语义、新学生反序音频、新学生常量音频，共10臂；重新生成旧分支并要求与保存输出maxabs<=2e-6。全部臂保存曲线。接收器不训练，须明确输入替换分布偏移，不能将失败自动归因接收器能力不足。

四例视频依旧按留句emotion内clip ID首条/seed42选择，六格为target upper+基座43、冻结base、VA旧/新、posterior旧/新；static/reverse/constant另给全长曲线。其他43及native无效帧逐值保护；不宣称整体口型身份情感已验收。

## 一次针对性结构修正

依据第一代constant-audio伪动态与OOF退步，追加`--paired-small`探索：hidden16，共享同一TCN计算真实输入与片均值常量输入，两者相减后再去均值。两次前向都保留梯度；常量音频的局部残差必须为零。这样移除纯位置/边界响应并降低容量，不新增loss。仍固定120轮/同seed/同fold/同目标。

容量和结构两项同时改变，只能称一次针对性候选，不能独立归因某一项；这是看到第一代结果后的开发探索。旧结果完整保留，后续报告两版，不从失败里挑好样例。主要判断是正常条件是否稳定胜静态且优于反序/常量，而非总loss或运动幅度。

## 实际终点：两版都已训练和评价，尚未通过

## 结论与下一优先级

本轮证明了一个工程缺陷（恒定声学也产生时间变化）并修复，但没有证明局部VA/类别时间轨迹可被当前音频特征准确预测。不能再承诺“补这个部件下次必成功”。两种语义本身也不是眉动作方向/时长的充分描述。

下一候选应将两个问题分开：保留可预测的全局情感与语音重音/停顿时间线作为条件，运动先验负责一对多的动作形状与自然节奏；不要求音频逐帧复制视觉VA噪声。它需要与同先验静态/反序语音事件对照，先验证真实条件能有效控制起势/保持/回落，再验证音频条件贡献。本轮未实现该候选，不把方案当结果。不要以进一步加轮次或幅度后处理替代证据。
