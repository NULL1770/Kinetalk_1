# 四组眉眼活动条件：三种子实测

**本轮已完成，活动可预测性未通过，不接入生成器。** 这不证明纯音频无法生成自然眉眼动作；它说明当前四维韵律、冻结全局表示与系数活动代理下，固定的小模型仍没有稳定的跨句增益。

## 实施与预算

按[预先固定协议](ACTIVITY_CONDITION_PROTOCOL_20260918.md)实现四组活动目标与音频预测，未修改身份、口型或全局情感基座。目标为原生25fps、32帧上下文中心8对帧的平滑速度RMS，经拟合片段加权65%分位阈值离散化。抬眉/压眉/眯眼/睁大组独立预测活动概率，不预测方向、完整轨迹或人工标注的动作起点。

三个训练种子20260918/19/20，每个静态30轮、冻结基线后时序修正30轮。时序修正596个参数，仅使用四个韵律通道、单一Brier目标、固定尺度1，没有挑epoch或seed。既有音频特征和全局基座已缓存/冻结；本轮读取、训练和评估合计58.40秒，不是完整面部模型从头训练的时间。

原smoke完成计算但JSON保存遇到NumPy布尔兼容错误；转成内置bool并增加序列化测试后，fresh smoke_v2完成23.66秒，5,369项独立审计通过。保留失败目录，不把失败运行描述为完成；正式训练使用修复后的源码。

## 下一步依据

本轮已把完整轨迹识别简化到596参数的四组边际活动预测，收益仍主要留在拟合数据。继续加轮数、叠loss或更换类似小head目前缺少依据。

下一项优先工作应是**独立核验活动监督**：按元数据固定采样原视频，检查真实眉眼运动与跟踪系数活动是否同步，区分眉眼变化、眨眼耦合、头姿耦合与跟踪噪声，并检查跨片段跟踪状态。当前门槛只衡量系数代理，不是人工肌肉动作真值；审计分数一致也不能证明标签正确。

若监督核验可信而纯音频条件仍弱，用户已接受的额外表达条件（独立短参考的活动风格、可控表达意图）是合理的生成路线。需明确推理输入并与只用音频的对照分开，不能读取目标片段GT或伪称音频可预测。运动先验负责自然的形状与持续过程；音频只调节经验证的可预测部分。以上是下一步工作方向，尚未实现，不能承诺成功或论文创新。
