# 稀疏眉部事件：实现与否决结果

2026-09-18。已实现事件教师、联合Student-t拟合器、持久事件生成器和审阅工具；**自然动态学习尚未成功，正式概率先验未拟合，没有神经网络长训练在跑**。这次完成的是可控动作机制及监督可用性检查，不能称性能提升。

## 已实际完成

- 自动HOLD→ONSET→APEX→RELEASE，阶段C2连接；外部保持/释放、分块续接与序列化续接。
- 系数空间的有方向峰值与回落端点，再转logit插值，避免沿用固定logit偏移时接近零的基准表情压缩动作幅度。幅度与活动频率分开控制，随机流独立。
- 32片隔离fresh raw监督提取、原16片像素初看、20个候选各5帧原像素窗口与32组曲线。100个像素帧槽逐个核对原审计RGB哈希。
- 四人各10秒、固定seed42的工程演示已渲染，250帧×4。人工指定抬眉/压眉两类峰值、12/8/18帧阶段与等待概率，**不是数据学到的动作**，无音频时机条件。其他47通道固定为run12首有效帧，不能拿它评价口型同步或身份几何。
- 四人×8seed×60秒延拓及四档幅度、三档活动控制检查均通过：零幅度静止、幅度不改时钟、同序号标记不随activity变、HOLD精确保持、回落精确回level、非眉通道不变、有限有界。工程设置的HOLD占比53.3%–59.5%、每分钟16–19事件是预设参数的结果，不是拟合自然节律。

## 教师为什么没有进入训练

固定阈值为max(0.035,6×fit残差MAD)，两组均落0.035；起势和回落至少4帧。v1把缺静止支撑的候选跨度扩至片段边界，再否决与其重叠的完整动作，导致53个有完整支撑候选、复合门后16个、最终只剩2个。这是冲突规则的过度保守，不能说原视频只有2个真实动作。

v2保留全部v1证据，只修正完整候选不能被不确定的大片跨度一概否决、异组可各自保留；阈值不变。得到20事件/16片，覆盖22.6%平滑差分能量，仍有65.3%落在不支持区域。20个中部分是并行组事件，单事件5维模型不能把这些重叠标记自动当独立样本。

更关键的是，可靠的“已知开始、已知自然结束”的等待区间为0，仅2个右删失区间。不能凭这组数据拟合停顿分布。拟合器保留最低样本和等待门控；未通过时拒绝正式拟合，合成工程演示明确分开。

根代理看完固定20个原像素窗口后发现，多条眉系数峰值与明显眼睑闭合同时出现，眉部本身变化则小或不确定。补充同MediaPipe眨眼系数诊断：20个窗口中11个含blink>0.5，8个在峰值±2帧内出现。该阈值为**事后定位**，且代理来自同模型，不能证明眨眼导致伪眉动作，也没有据此删除事件后重新拟合。M003 happy/neutral、W011 happy/neutral、W014 neutral等窗口支持进一步拆分眨眼共现与眉部独立动作；M005 angry有可见眉间/内侧变化，但原像素峰与自动阶段端点的对应尚不够确定。

16片初看是助手观察，不是人工盲评。其文字落盘前根代理已发来两个候选时间，虽审阅者报告初看在消息之前完成，仍不能称严格预封存的独立盲评；初稿中的M005 angry纯down判断也过强。补充说明和逐窗口根代理观察保存在产物目录，没有回写标签。
