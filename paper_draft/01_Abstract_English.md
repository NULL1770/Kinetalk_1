# KineTalk: Emotion and Personal Motion Response Generation with a Neutral Articulation Base

## Abstract

Speech-driven 3D facial animation must synchronize articulation while expressing emotion and speaker-specific motion. The mapping from speech to facial movement is inherently one-to-many: the same utterance can support different eyebrow, eyelid, mouth-corner, jaw, and duration patterns. A reference utterance also mixes linguistic content, affect, and personal movement habits, so directly copying or subtracting an unaligned trajectory is unsuitable for cross-utterance control. We present KineTalk, a conditional response framework that uses a neutral articulation base as the coordinate system for expressive generation. Query speech first produces a temporally aligned articulation base. During training, a privileged teacher observes the motion posterior and transfers global affective semantics to an audio-only student that receives emotion2vec features and prosody at inference. A reference encoder jointly reads reference motion, its own audio, and content context to form a conditional personal motion response that can be reused across utterances. Content, affect, reference response, and an audio-conditioned event process are combined by a factor-interaction temporal residual decoder to generate full-face ARKit motion. The event process represents locally ambiguous performance through event occurrence, duration, and amplitude distributions, allowing multiple plausible local realizations without treating one observed sequence as the unique emotional trajectory. Experiments on labeled MEAD data and the broader content and speaker coverage of HDTF evaluate articulation reconstruction, affect readability, reference swapping, and conditional motion variation under held-sentence and unseen-speaker protocols. The results support a unified generation path in which articulation timing, affective state, personal response, and local stochastic variation can be analyzed through separate, reproducible controls.

**Keywords:** speech-driven 3D facial animation; neutral articulation base; privileged teacher–audio student; conditional personal motion response; audio-conditioned event process; ARKit blendshape
