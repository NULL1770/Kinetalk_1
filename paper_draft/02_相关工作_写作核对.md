# 第2节相关工作：提纲、证据与自审

更新：2026-09-22。对应 [中文版相关工作](02_相关工作_中文版.md)。本文件为作者核对记录，不进入论文正文。

## 小节提纲

- **2.1 语音驱动的三维面部运动建模：** VOCA、MeshTalk、FaceFormer、FaceXHuBERT、CodeTalker、KMTalk、FaceDiffuser、DiffSpeaker 和 GLDiTalker，说明连续回归、跨模态解耦、运动先验与概率生成的演进。
- **2.2 参考条件下的个性化与说话风格建模：** Imitator、TalkingStyle、StyleTalk 和 DiffPoseTalk，强调参考动作中的发音内容与跨语句个体特征分离问题。
- **2.3 情感与表现力面部动画：** EmoTalk、情感嵌入、PESTalk、DEITalk、MEDTalk、EmoFace 和 EmotionFace，区分全局情感、动态强度、说话人情感风格与局部运动。

## 主张—证据映射

1. **Claim:** 连续三维语音驱动方法逐步引入长时语音表征、跨模态解耦、离散运动先验和概率生成。  
   **Evidence:** 正文 [1]、[4]–[7]、[11]–[15] 的 CVPR、ICCV、MIG、ECCV Workshops、IEEE 和 IJCAI 论文及 DOI。  
   **Status:** supported。

2. **Claim:** 参考条件可以用于保持个体化运动和说话风格，但参考序列同时包含说话人特征与参考语句发音。  
   **Evidence:** Imitator [8]、TalkingStyle [10]、StyleTalk [9]、DiffPoseTalk [13] 的论文机制；KineTalk 的参考残差实现。  
   **Status:** supported as mechanism comparison。

3. **Claim:** 情感三维面部动画使用内容—情感解耦、连续情感嵌入、个性化情感风格和动态强度等条件。  
   **Evidence:** EmoTalk [16]、ICASSP 情感嵌入 [17]、PESTalk [18]、DEITalk [19]、MEDTalk [2]、EmoFace [20]、EmotionFace [21]。  
   **Status:** supported；正文没有把整体情感强度写成事件级音频对齐证明。

4. **Claim:** KineTalk 将发音基座、参考执行特征和情感表达分配到不同信息来源与输出路径。  
   **Evidence:** [引言](01_引言_中文版.md)、项目实现和实验记录。  
   **Status:** supported as implementation description；局部眉眼时序收益仍需实验。

## 文献核验说明

- 正文使用 20 条参考文献；均有 DOI、CVF/ACM/AAAI/IEEE/Springer/IJCAI 官方记录或本地原文缓存。
- 本节不纳入未能稳定核对完整元数据的条目。
- “身份”表示参考语音—动作中提取的说话人执行特征，不表示静态几何身份。
- “动态”区分全局强度、区域活动幅度和逐帧事件时间对应。

## 五维自审

- **贡献边界：** 相关工作只描述已有技术与 KineTalk 的问题设置，不使用作者自辩式表述。
- **写作清晰度：** 三个小节分别回答“如何从语音生成运动”“如何从参考中保持个体化”“如何生成情感表现”。
- **术语一致性：** 使用“发音基座”“参考执行特征”“全局情感”“表达残差”“局部时变动态”五个稳定术语。
- **证据边界：** 不把情感分类、区域幅度或扩散采样多样性直接解释为眉眼事件级音频对齐。
- **实验衔接：** 末段提出统一 ARKit52、口型保护、情感保持和反事实音频对照的必要性。
