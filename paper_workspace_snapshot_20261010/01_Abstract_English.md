# ARFTalk: Articulation-Aware Residual Flow Matching for Expressive Speech-Driven 3D Facial Animation

## Abstract

Speech-driven 3D facial animation aims to synthesize facial motion that is synchronized with speech and conveys expressive content. Lip synchronization and emotional expression are important factors in producing natural facial animation. However, articulatory motion, speaker-related motion characteristics, and emotional expression are entangled in observed facial motion, which complicates controllable 3D facial animation. We present ARFTalk, an articulation-aware residual flow matching framework for ARKit blendshape coefficients. The framework first uses a speech-conditioned articulation base to model speech-related mouth motion and constructs a cross-utterance speaker-related motion-style condition by subtracting the articulation component predicted for each reference utterance. A motion-residual emotion teacher then learns a global emotion representation from target motions after subtracting the predicted articulation motion and speaker-related static offsets, and guides emotion modeling in the audio branch. The conditional residual generator combines speaker-related conditions, emotion conditions, and acoustic temporal features to generate residual motion. The generated residual is combined with the articulation-base motion and static offsets to synthesize expressive facial motion.

**Keywords:** Speech-driven 3D facial animation; articulation-aware motion modeling; reference-conditioned facial animation; cross-modal emotion distillation; residual flow matching;
